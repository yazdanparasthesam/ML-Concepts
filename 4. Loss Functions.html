🎯 4. Loss Functions — از پایه تا Senior ML

1. اول: Loss Function چیست؟

فرض کن:

$$y$$

Target واقعی است و:

$$\hat{y}$$

Prediction مدل است.

Loss تابعی است که مشخص می‌کند:

Prediction مدل چقدر با Target واقعی فاصله دارد.

به‌صورت کلی:

$$L(y, \hat{y})$$

مدل تلاش می‌کند:

$$\min_{\theta} \frac{1}{N} \sum_{i=1}^{N} L(y_i, f_{\theta}(x_i))$$

را حل کند.

یعنی پارامترهای مدل:

$$\theta$$

را طوری پیدا کند که Loss کمینه شود.

2. Loss Function vs Metric

این تفاوت را در مصاحبه خیلی مهم است.

Loss

برای Training / Optimization استفاده می‌شود.

مثلاً:

Cross Entropy MSE Huber Triplet Loss
Metric

برای Evaluation استفاده می‌شود.

مثلاً:

Accuracy F1 ROC-AUC PR-AUC MAE RMSE NDCG MAP

اما گاهی یک Metric می‌تواند Loss هم باشد.

مثلاً:

MSE

هم می‌تواند Objective باشد و هم Evaluation Metric.

3. چرا نمی‌توانیم همیشه همان Metric را Loss کنیم؟

چون Loss باید معمولاً برای Optimization مناسب باشد.

مثلاً Accuracy:

$$Accuracy = \frac{Correct}{N}$$

تابعی تقریباً discrete و non-differentiable نسبت به پارامترهای مدل است.

Gradient-based optimization با آن راحت نیست.

بنابراین برای Classification معمولاً از:

CrossEntropy

استفاده می‌کنیم، نه Accuracy.

بخش اول: Regression Losses

4. MSE — Mean Squared Error

فرمول:

$$MSE = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

Residual:

$$e_i = y_i - \hat{y}_i$$

پس:

$$MSE = \frac{1}{N} \sum e_i^2$$

5. چرا Error را Square می‌کنیم؟

دو دلیل مهم:

1. خطاهای مثبت و منفی همدیگر را خنثی نکنند

اگر:

+10 -10

را جمع کنیم:

$$10 + (-10) = 0$$

در حالی که مدل خطای زیادی دارد.

با Square:

$$10^2 + (-10)^2 = 200$$

2. خطاهای بزرگ را شدیداً جریمه کنیم

مثلاً:

Error = 2 → Loss = 4 Error = 10 → Loss = 100

پس MSE به Outlier حساس است.

6. Gradient MSE

برای یک Sample:

$$L = (y - \hat{y})^2$$

نسبت به Prediction:

$$\frac{\partial L}{\partial \hat{y}} = 2(\hat{y} - y)$$

یعنی:

$$\nabla_{\hat{y}} L = 2(\hat{y} - y)$$

هرچه Error بزرگ‌تر باشد:

Gradient بزرگ‌تر است.

7. مزیت MSE

  • Differentiable
  • Smooth
  • Optimization نسبتاً راحت
  • برای Gaussian noise مناسب
  • در Linear Regression بسیار رایج

8. MSE و Gaussian Assumption

یک نکته Senior بسیار مهم:

اگر فرض کنیم:

$$y = f(x) + \epsilon$$

و:

$$\epsilon \sim N(0, \sigma^2)$$

باشد، Maximum Likelihood Estimation منجر به کمینه‌کردن Sum of Squared Errors می‌شود.

یعنی:

$$Gaussian Noise \Rightarrow MSE$$

به همین دلیل MSE فقط یک انتخاب تصادفی نیست؛ پشت آن یک مدل احتمالاتی وجود دارد.

9. مشکل MSE

Outlier:

Normal errors: 1 2 3 Outlier: 100

MSE:

$$100^2 = 10000$$

بنابراین یک Outlier می‌تواند Loss را کاملاً تحت تأثیر قرار دهد.

10. MAE — Mean Absolute Error

فرمول:

$$MAE = \frac{1}{N} \sum |y_i - \hat{y}_i|$$

یا:

$$MAE = \frac{1}{N} \sum |e_i|$$

11. رفتار MAE

مثلاً:

Error = 2 → Loss = 2 Error = 10 → Loss = 10

برخلاف MSE:

Error = 2 → 4 Error = 10 → 100

بنابراین MAE نسبت به Outlier مقاوم‌تر است.

12. Gradient MAE

برای:

$$L = |y - \hat{y}|$$

داریم:

$$\frac{\partial L}{\partial \hat{y}} = sign(\hat{y} - y)$$

یعنی تقریباً:

Error > 0 → +1 Error < 0 → -1

Magnitude Gradient تقریباً ثابت است.

13. مشکل MAE

MAE در:

$$e = 0$$

مشتق کلاسیک ندارد.

چون:

|e|

در صفر یک گوشه دارد.

در عمل Optimization با Subgradient انجام می‌شود.

14. MSE vs MAE

ویژگیMSEMAE
Outlier sensitivityزیادکمتر
Gradientمتناسب با Errorتقریباً ثابت
Smoothبلهدر صفر نه
Optimizationراحتکمی سخت‌تر
Noise assumptionGaussianLaplace
Central tendencyMeanMedian

15. MAE و Laplace Distribution

اگر:

$$\epsilon \sim Laplace(0, b)$$

باشد، Maximum Likelihood با کمینه‌کردن:

$$\sum |y - \hat{y}|$$

مرتبط می‌شود.

پس:

Gaussian noise → MSE Laplace noise → MAE

یک نکته بسیار مهم برای مصاحبه Senior.

16. Huber Loss

Huber Loss تلاش می‌کند:

مزایای MSE + Robustness شبیه MAE

را ترکیب کند.

فرمول:

$$L_{\delta}(e) = \begin{cases} \frac{1}{2}e^2 & |e| \le \delta \\ \delta(|e| - \frac{1}{2}\delta) & |e| > \delta \end{cases}$$

که:

$$e = y - \hat{y}$$

است.

17. رفتار Huber

اگر Error کوچک باشد:

$$|e| \le \delta$$

رفتار شبیه MSE:

$$L = \frac{1}{2}e^2$$

اگر Error بزرگ باشد:

$$|e| > \delta$$

رفتار شبیه MAE:

$$L \approx |e|$$

18. چرا Huber بسیار مهم است؟

چون:

Small Error ↓ Quadratic ↓ Stable smooth optimization Large Error ↓ Linear ↓ Less sensitive to outliers

19. Gradient Huber

برای Error کوچک:

$$\frac{\partial L}{\partial \hat{y}} \propto e$$

برای Error بزرگ:

$$\frac{\partial L}{\partial \hat{y}}$$

تقریباً محدود می‌شود.

یعنی Gradient مثل MSE بدون محدودیت رشد نمی‌کند.

این باعث Robustness بیشتر می‌شود.

20. پارامتر δ در Huber

$$\delta$$

نقطه‌ای است که Loss از:

Quadratic

به:

Linear

تغییر می‌کند.

δ کوچک

مدل سریع‌تر وارد رفتار MAE می‌شود.

δ بزرگ

مدل بیشتر شبیه MSE رفتار می‌کند.

21. Log-Cosh Loss

فرمول:

$$L(e) = \log(\cosh(e))$$

که:

$$e = y - \hat{y}$$

است.

22. رفتار Log-Cosh

برای Error کوچک:

$$\log(\cosh(e)) \approx \frac{e^2}{2}$$

یعنی شبیه MSE.

برای Error بزرگ:

$$\log(\cosh(e)) \approx |e| - \log 2$$

یعنی شبیه MAE.

پس:

$$LogCosh \approx MSE \text{ for small errors}$$

و:

$$LogCosh \approx MAE \text{ for large errors}$$

23. Gradient Log-Cosh

یک ویژگی بسیار جالب:

$$\frac{d}{de} \log(\cosh(e)) = \tanh(e)$$

و:

$$-1 < \tanh(e) < 1$$

پس Gradient bounded است.

این ویژگی می‌تواند در برابر Outlierها مفید باشد.

24. Huber vs Log-Cosh

هر دو:

Small error → quadratic-like Large error → linear-like

اما Huber:

Piecewise است δ دارد کنترل مستقیم transition دارد

Log-Cosh:

Smooth است مشتق‌پذیری بسیار خوب دارد Transition نرم است

25. Quantile Loss

این Loss بسیار مهم است، مخصوصاً در:

Risk modeling Demand forecasting Financial forecasting Prediction intervals Uncertainty estimation

26. Quantile Regression چیست؟

به جای Predict کردن:

$$E[Y|X]$$

می‌توانی Quantile خاصی را Predict کنی.

مثلاً:

$$Q_{0.9}(Y|X)$$

یعنی مقداری که تقریباً 90٪ مشاهدات زیر آن قرار می‌گیرند.

27. Quantile Loss / Pinball Loss

فرمول:

$$L_{\tau}(y, \hat{y}) = \begin{cases} \tau(y - \hat{y}) & y \ge \hat{y} \\ (1-\tau)(\hat{y} - y) & y < \hat{y} \end{cases}$$

که:

$$0 < \tau < 1$$

است.

28. چرا Loss نامتقارن است؟

فرض کن:

$$\tau = 0.9$$

اگر مدل Underpredict کند:

$$y > \hat{y}$$

جریمه:

$$0.9(y - \hat{y})$$

اما اگر Overpredict کند:

$$\hat{y} > y$$

جریمه:

$$0.1(\hat{y} - y)$$

پس Underprediction شدیدتر جریمه می‌شود.

29. کاربرد Quantile Loss

مثلاً Forecasting:

P10 P50 P90

می‌توانی سه مدل داشته باشی:

$$\tau = 0.1$$
$$\tau = 0.5$$
$$\tau = 0.9$$

و یک Prediction Interval تقریبی بسازی.

30. نکته مهم Quantile Loss

وقتی:

$$\tau = 0.5$$

باشد، Quantile Loss با Median مرتبط می‌شود.

یعنی:

Q_{0.5}

تقریباً Median است.

بخش دوم: Classification Losses

31. Binary Cross Entropy

برای Binary Classification:

$$y \in \{0, 1\}$$

و:

$$p = P(y=1|x)$$

فرمول:

$$L = -[y \log p + (1-y) \log(1-p)]$$

32. اگر y=1 باشد

Loss می‌شود:

$$L = -\log p$$

پس:

p=0.99 → Loss ≈ 0.01 p=0.5 → Loss ≈ 0.69 p=0.01 → Loss ≈ 4.61

یعنی اگر مدل با Confidence بالا اشتباه کند، Loss بسیار بزرگ می‌شود.

33. اگر y=0 باشد

$$L = -\log(1-p)$$

اگر:

p=0.01

Loss کم است.

ولی:

p=0.99

Loss بسیار بزرگ می‌شود.

34. چرا Cross Entropy؟

چون با:

Maximum Likelihood Estimation

مرتبط است.

اگر:

$$Y \sim Bernoulli(p)$$

باشد، Negative Log-Likelihood همان Binary Cross Entropy می‌شود.

پس:

$$BCE = Negative \ Log \ Likelihood$$

برای Bernoulli model.

35. Logit چیست؟

مدل معمولاً مستقیماً Probability تولید نمی‌کند.

ممکن است:

$$z$$

را تولید کند.

بعد:

$$p = \sigma(z)$$

که:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

است.

36. BCE with Logits

در عمل بهتر است از:

BCEWithLogitsLoss

استفاده شود.

چرا؟

چون:

Sigmoid + Log

را به شکل Numerically Stable ترکیب می‌کند.

این برای جلوگیری از مشکلات:

log(0) overflow underflow

مهم است.

37. Binary Cross Entropy و Decision Threshold

Loss با:

Probability quality

کار می‌کند.

اما Classification نهایی ممکن است با:

threshold = 0.5

انجام شود.

این دو را قاطی نکن.

مدل می‌تواند:

BCE

را minimize کند ولی threshold بهینه برای Business Objective الزاماً 0.5 نباشد.

38. Categorical Cross Entropy

برای Multi-Class Classification.

مثلاً:

Cat Dog Horse

مدل:

$$p_1, p_2, p_3$$

تولید می‌کند و:

$$\sum p_i = 1$$

است.

39. فرمول Categorical Cross Entropy

اگر:

$$y_i$$

One-Hot Label باشد:

$$L = -\sum_{c=1}^{C} y_c \log p_c$$

اگر Class واقعی:

Dog

باشد:

$$y = [0, 1, 0]$$

آنگاه:

$$L = -\log p_{dog}$$

40. Sparse Categorical Cross Entropy

از نظر ریاضی هدف تقریباً همان Categorical Cross Entropy است.

تفاوت در Representation Label است.

Categorical
[0, 1, 0]
Sparse
1

یعنی:

Categorical CE → One-Hot Labels Sparse Categorical CE → Integer Class IDs

41. چرا Sparse مهم است؟

فرض کن:

Classes = 100,000 Samples = 10M

ساخت One-Hot Matrix می‌تواند حافظه زیادی مصرف کند.

Sparse representation بسیار کارآمدتر است.

42. Softmax

برای Multi-Class Classification معمولاً:

$$p_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

است.

که:

$$\sum_i p_i = 1$$

است.

43. Softmax + Cross Entropy

در بسیاری از Frameworkها بهتر است:

Softmax + CrossEntropy

به‌صورت fused/numerically stable implementation استفاده شود.

مثلاً:

CrossEntropyLoss

معمولاً logits را مستقیماً می‌گیرد.

44. Hinge Loss

Loss معروف در:

Support Vector Machines

فرمول:

$$L = \max(0, 1 - y f(x))$$

که:

$$y \in \{-1, +1\}$$

است.

45. رفتار Hinge

اگر:

$$y f(x) \ge 1$$

آنگاه:

$$L = 0$$

یعنی مدل نه‌تنها باید درست Classification کند، بلکه باید با Margin مناسب این کار را انجام دهد.

46. مثال

اگر:

y = +1 f(x) = 2

آنگاه:

$$y f(x) = 2$$

و:

$$L = 0$$

اما:

f(x) = 0.5

آنگاه:

$$L = 1 - 0.5 = 0.5$$

حتی اگر Prediction درست باشد، هنوز Margin کافی نیست.

47. Hinge Loss و Margin

این نکته کلیدی است:

Hinge Loss فقط Correctness را تشویق نمی‌کند؛ Margin را هم تشویق می‌کند.

این تفاوت مهم آن با Cross Entropy است.

48. Focal Loss

برای:

Highly Imbalanced Classification

خیلی مهم است.

خصوصاً:

Object Detection Fraud Detection Rare-event detection

49. ایده Focal Loss

فرض کن:

Easy Negative: p(correct) = 0.99 Hard Positive: p(correct) = 0.20

در Dataset بسیار Imbalanced، تعداد Easy Negatives می‌تواند بسیار زیاد باشد.

پس مدل ممکن است تحت تأثیر Easy Examples قرار بگیرد.

Focal Loss می‌گوید:

Easy examples را down-weight کن و روی Hard examples تمرکز کن.

50. فرمول Focal Loss

برای Binary Classification:

$$FL(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$$

که:

$$p_t = \begin{cases} p & y=1 \\ 1-p & y=0 \end{cases}$$

است.

51. نقش γ

اگر:

$$\gamma = 0$$

باشد:

$$FL = -\alpha_t \log(p_t)$$

یعنی تقریباً Weighted Cross Entropy.

اگر:

$$\gamma > 0$$

باشد:

Easy examples ↓ Weight کاهش می‌یابد

52. مثال Focal

اگر:

$$p_t = 0.99$$

و:

$$\gamma = 2$$

آنگاه:

$$(1 - p_t)^2 = (0.01)^2 = 0.0001$$

پس Easy Example تقریباً Weight بسیار کمی می‌گیرد.

اما اگر:

$$p_t = 0.2$$

آنگاه:

$$(0.8)^2 = 0.64$$

پس Hard Example هنوز Weight زیادی دارد.

53. α در Focal Loss

$$\alpha_t$$

برای کنترل Class Imbalance است.

بنابراین:

γ → focus on hard examples α → class balancing

این دو را در مصاحبه جدا کن.

54. مشکل احتمالی Focal Loss

اگر γ را بیش از حد بزرگ کنی:

Easy examples → almost ignored

ممکن است:

  • Training سخت شود
  • Gradient مؤثر کم شود
  • Calibration بدتر شود
  • Model روی Hard Examples بیش از حد تمرکز کند

بنابراین γ باید Tune شود.

55. Label Smoothing

Label Smoothing در اصل یک Loss مستقل کلاسیک مثل MSE نیست؛ بیشتر یک Modification/Regularization of Cross-Entropy Targets است.

مثلاً Target واقعی:

[0, 1, 0]

به:

[0.05, 0.90, 0.05]

تبدیل می‌شود.

56. چرا Label Smoothing؟

بدون Label Smoothing مدل ممکن است بیش از حد مطمئن شود:

P(correct) = 0.999999

Label Smoothing مدل را از:

Extreme Confidence

دور می‌کند.

57. ایده ریاضی

به جای:

$$y = 1$$

برای Class درست، Target را مثلاً:

$$y' = 1 - \epsilon$$

می‌کنیم.

و برای سایر کلاس‌ها مقدار کوچکی می‌دهیم.

58. مزایای Label Smoothing

می‌تواند:

  • Overconfidence را کاهش دهد
  • Generalization را بهتر کند
  • Calibration را بهبود دهد
  • Overfitting را کاهش دهد

اما همیشه تضمینی نیست.

59. نکته مهم Label Smoothing

Label Smoothing می‌تواند Probability calibration را تغییر دهد.

اگر برای کاربردت:

Highly calibrated probabilities

مهم باشد، باید اثر آن را جداگانه بررسی کنی.

بخش سوم: Ranking / Representation Losses

اینجا باید یک تفاوت مهم را بفهمی:

در Classification معمولاً می‌گویی:

این Sample متعلق به Class X است.

اما در Ranking می‌خواهی:

A باید بالاتر از B قرار بگیرد.

60. Pairwise Loss

در Ranking یک جفت داریم:

Query ├── Positive item └── Negative item

می‌خواهیم:

$$score(pos) > score(neg)$$

باشد.

61. Pairwise Hinge / Margin Loss

مثلاً:

$$L = \max(0, m - s_{pos} + s_{neg})$$

که:

$$m > 0$$

است.

می‌خواهیم:

$$s_{pos} \ge s_{neg} + m$$

باشد.

62. مثال

فرض کن:

Positive score = 0.9 Negative score = 0.2 Margin = 0.5

داریم:

$$0.9 - 0.2 = 0.7$$

چون:

$$0.7 > 0.5$$

Loss:

$$0$$

63. اگر:

Positive = 0.6 Negative = 0.4 Margin = 0.5

آنگاه:

$$0.6 - 0.4 = 0.2$$

و:

$$L = 0.5 - 0.2 = 0.3$$

64. کاربرد Pairwise Loss

Search Ranking Recommendation Information Retrieval Learning-to-Rank Product Ranking

65. Triplet Loss

بسیار مهم در:

Face Recognition Metric Learning Image Retrieval Person Re-identification Similarity Learning

سه Sample داریم:

Anchor Positive Negative

66. هدف Triplet Loss

می‌خواهیم:

$$d(A, P) < d(A, N)$$

باشد.

یعنی:

Anchor نزدیک Positive Anchor دور Negative

67. فرمول Triplet Loss

$$L = \max(0, d(A, P) - d(A, N) + m)$$

که:

$$m$$

Margin است.

68. مثال

فرض کن:

d(A,P) = 0.2 d(A,N) = 0.8 m = 0.5

پس:

$$0.2 - 0.8 + 0.5 = -0.1$$

بنابراین:

$$L = 0$$

69. اگر Negative خیلی نزدیک باشد

مثلاً:

d(A,P) = 0.3 d(A,N) = 0.5 m = 0.5

آنگاه:

$$L = 0.3 - 0.5 + 0.5 = 0.3$$

پس مدل باید Embeddingها را بهتر جدا کند.

70. Hard Negative Mining

یک نکته بسیار مهم Senior در Triplet Loss.

فرض کن:

Anchor Positive Negative 1 → خیلی دور Negative 2 → خیلی دور Negative 3 → خیلی نزدیک

Negative 3 برای آموزش بسیار informativeتر است.

به این می‌گوییم:

Hard Negative

71. چرا Hard Negative Mining مهم است؟

اگر همیشه Negativeهای خیلی آسان انتخاب شوند:

$$d(A, N) >> d(A, P)$$

آنگاه:

$$L = 0$$

برای اکثر Tripletها.

پس Gradient کمی دریافت می‌کنی.

72. اما Hard Negative بیش از حد هم خطرناک است

اگر Negative واقعاً False Negative باشد:

A و N در واقع semantic مشابه‌اند

مدل را مجبور می‌کنی چیزهایی را که باید نزدیک باشند از هم دور کند.

این می‌تواند Training را خراب کند.

پس:

Hard Negative Mining باید با کیفیت داده و احتمال False Negative هماهنگ باشد.

73. Contrastive Loss

Contrastive Learning معمولاً با Pair کار می‌کند.

دو Sample داریم:

(x1, x2)

و Label:

Similar Dissimilar

74. ایده Contrastive Loss

اگر Similar:

$$d(x_1, x_2) \rightarrow 0$$

اگر Dissimilar:

$$d(x_1, x_2) \ge m$$

75. فرمول کلاسیک Contrastive Loss

یک فرم رایج:

$$L = y d^2 + (1-y) \max(0, m - d)^2$$

که مثلاً:

y=1 → Similar y=0 → Dissimilar

است.

76. اگر Similar باشند

$$y = 1$$

پس:

$$L = d^2$$

مدل تلاش می‌کند:

$$d \rightarrow 0$$

77. اگر Dissimilar باشند

$$y = 0$$

پس:

$$L = \max(0, m - d)^2$$

اگر:

$$d > m$$

Loss صفر است.

78. Contrastive vs Triplet

Contrastive

دو Sample:

Anchor ↔ Other
Triplet

سه Sample:

Anchor Positive Negative

Contrastive مستقیماً Similarity/Dissimilarity pair را یاد می‌گیرد.

Triplet یک relative ordering یاد می‌گیرد:

$$A-P < A-N$$

79. Pairwise vs Triplet vs Contrastive

Lossورودیهدف
PairwisePositive + NegativeRanking
ContrastivePair + Similarity LabelSimilar/Dissimilar
TripletAnchor + Positive + NegativeRelative Distance

البته در ادبیات ML، اصطلاحات Pairwise/Contrastive گاهی با هم overlap دارند؛ مهم این است که objective دقیق را بررسی کنی، نه فقط اسم Loss را.

80. Loss Functions و Gradient

این قسمت برای Senior بسیار مهم است.

صرفاً نگو:

MSE برای Regression است.

باید بدانی Gradient چه می‌کند.

MSE
$$gradient \propto error$$

پس:

Large Error → Large Gradient
MAE
gradient ≈ constant magnitude

پس:

Outlier → Gradient not proportional to huge error
Huber
Small Error → MSE-like Large Error → MAE-like
Log-Cosh
Gradient = tanh(error)

پس Gradient bounded است.

Cross Entropy

وقتی با logits استفاده شود، Gradient نسبت به logits ساختار بسیار ساده و مناسب دارد:

$$\frac{\partial L}{\partial z} = p - y$$

برای Softmax + Cross Entropy.

این یکی از دلایل مهم محبوبیت آن است.

🧠 اگر برای Senior ML مصاحبه می‌خواهی، این سؤال‌ها را باید بتوانی جواب بدهی

1.

Why would you use Huber instead of MSE?
→ وقتی Outlier داری ولی همچنان رفتار smooth و quadratic برای خطاهای کوچک می‌خواهی.

2.

Why is MAE more robust than MSE?
→ چون خطا را خطی جریمه می‌کند، نه quadratic.

3.

Why is MSE related to Gaussian noise?
→ چون Minimizing Squared Error معادل Maximum Likelihood تحت Gaussian noise است.

4.

Why is MAE related to Laplace noise?
→ چون Negative Log-Likelihood توزیع Laplace متناسب با Absolute Error است.

5.

Why use Focal Loss?
→ برای کاهش contribution نمونه‌های بسیار آسان و تمرکز بیشتر روی Hard Examples، مخصوصاً در Class Imbalance.

6.

Difference between α and γ in Focal Loss?
α → Class weighting, γ → Hard−example focusing

7.

BCE vs Categorical CE?
BCE → Binary / independent Bernoulli outputs, Categorical CE → mutually exclusive multi-class output

8.

Categorical CE vs Sparse Categorical CE?
هدف ریاضی مشابه است؛ تفاوت اصلی در نحوه representation label است: One-Hot → Categorical CE, Integer ID → Sparse CE

9.

Why isn't Accuracy usually used as a training loss?
چون برای Gradient-based Optimization مناسب نیست و نسبت به تغییرات کوچک در prediction رفتار differentiable مناسبی ندارد.

10.

Triplet Loss vs Contrastive Loss?
Contrastive → pair-based similarity learning, Triplet → relative distance/order among anchor-positive-negative

11.

What does Quantile Loss give you?
به جای صرفاً Mean Prediction، می‌تواند Conditional Quantile مثل Q_{0.1}, Q_{0.5}, Q_{0.9} را یاد بگیرد.

12.

Is the lowest training loss always the best model?
خیر. چون هدف اصلی Generalization است، نه صرفاً Training Loss پایین. و به همین دلیل است که تمام مباحث قبلی که با هم خواندیم—Train/Validation/Test، Cross-Validation، Leakage، Bias-Variance و Generalization—مستقیماً به Loss Function وصل می‌شوند.
