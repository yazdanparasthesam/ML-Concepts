🌳 9. Classical Machine Learning Algorithms

حتماً. این بخش Classical ML Algorithms یکی از مهم‌ترین بخش‌ها برای سطح Senior است؛ چون در مصاحبه Senior معمولاً فقط نمی‌پرسند «XGBoost چیست؟»، بلکه می‌پرسند:

  • چرا Linear Regression را به XGBoost ترجیح می‌دهی؟
  • چه زمانی KNN بهتر از یک مدل پیچیده است؟
  • چرا Random Forest نسبت به یک Decision Tree بهتر generalize می‌کند؟
  • XGBoost و LightGBM و CatBoost دقیقاً چه تفاوتی دارند؟
  • چرا SVM با Kernel می‌تواند nonlinear باشد؟
  • چرا K-Means برای بعضی داده‌ها مناسب نیست؟
  • چه زمانی Naive Bayes با وجود فرض اشتباه استقلال، عملکرد خوبی دارد؟
  • GMM چه تفاوتی با K-Means دارد؟
  • Scaling برای کدام مدل‌ها ضروری است؟
  • Complexity و Training/Inference Cost هر مدل چیست؟
  • مدل‌ها با missing values، categorical features، outlier و high-dimensional data چگونه رفتار می‌کنند؟

بخش اول — Linear Models

1. Linear Regression

ایده اصلی

Linear Regression می‌خواهد رابطه‌ای بین Features و Target پیدا کند که به شکل خطی باشد.

برای یک Feature:

$$\hat{y} = \beta_0 + \beta_1x$$

برای چند Feature:

$$\boxed{\hat{y} = \beta_0 + \beta_1x_1 + \beta_2x_2 + \cdots + \beta_px_p}$$

یا:

$$\hat{y} = X\beta$$

مثال

فرض کن می‌خواهیم قیمت خانه را پیش‌بینی کنیم:

Area Rooms Age Location Score │ ▼ Linear Regression │ ▼ House Price

مدل ممکن است یاد بگیرد:

$$Price = 50000 + 3000Area + 20000Rooms - 1000Age$$

2. هدف Linear Regression

معمولاً Mean Squared Error را کمینه می‌کنیم:

$$\boxed{MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$$

بنابراین:

$$\boxed{\min_{\beta} \sum_i(y_i - X_i\beta)^2}$$

3. Least Squares

Linear Regression کلاسیک از:

Ordinary Least Squares — OLS

استفاده می‌کند.

یک نقطه را بکشید تا خط دوباره برازش شود.
بازخورد بدهید

آمار مدل

\(\hat{y} = b_0 + b_1x\)

\(\hat{y} = 8.49 - 0.54x\)

R² = 0.72 · b₀ = عرض از مبدأ · b₁ = شیب · حداقل مربعات، مجذور فاصله های باقیمانده عمودی را کمینه می کند.

هدف این است که مجموع مربع فاصله‌های عمودی بین:

Actual y │ │ residual ▼ Predicted y

کمینه شود.

4. Closed-Form Solution

در شرایط مناسب:

$$\boxed{\hat{\beta} = (X^TX)^{-1}X^Ty}$$

این همان Normal Equation است.

اما در عمل همیشه Matrix Inverse را مستقیماً حساب نمی‌کنیم.

معمولاً از روش‌هایی مثل:

QR decomposition SVD iterative optimization

استفاده می‌شود.

5. چرا Matrix Inverse خطرناک است؟

اگر:

$$X^TX$$

ill-conditioned یا singular باشد، inverse می‌تواند از نظر عددی ناپایدار باشد.

این اتفاق خصوصاً با:

Multicollinearity

رخ می‌دهد.

6. Assumptions در Linear Regression

برای استنباط آماری کلاسیک، assumptions مهم هستند:

1. Linearity

رابطه conditional mean تقریباً خطی باشد:

$$E[Y|X] = X\beta$$
2. Independence

مشاهدات وابسته نباشند.

3. Homoscedasticity

Variance خطاها ثابت باشد:

$$Var(\epsilon|X) = \sigma^2$$
4. Zero Conditional Mean
$$E[\epsilon|X] = 0$$
5. Normality of Errors

برای برخی inferenceهای کلاسیک مهم است، ولی برای خود point prediction الزام مطلق نیست.

7. نکته بسیار مهم Senior

خیلی‌ها می‌گویند:

Linear Regression فقط وقتی خوب است که داده‌ها Normal باشند.

این اشتباه است.

Normality بیشتر برای:

statistical inference / confidence intervals / hypothesis tests

مهم است، نه اینکه الزاماً خود Linear Regression نتواند prediction انجام دهد.

8. Multicollinearity

اگر:

$$X_1 \approx X_2$$

باشد، coefficients ممکن است ناپایدار شوند.

مثلاً:

House Size Number of Rooms

ممکن است شدیداً correlated باشند.

نتیجه:

coefficient variance بالا interpretability ضعیف instability

9. مزایای Linear Regression

ساده سریع قابل تفسیر baseline عالی مناسب برای رابطه تقریباً خطی training ارزان مناسب برای datasets بزرگ و sparse

10. محدودیت‌ها

رابطه‌های nonlinear را به‌صورت مستقیم یاد نمی‌گیرد. نسبت به outlierها با MSE حساس است. multicollinearity می‌تواند مشکل‌ساز شود. feature engineering ممکن است لازم باشد.

11. Polynomial Regression

اگر رابطه خطی نباشد می‌توان Features را به polynomial تبدیل کرد.

مثلاً:

$$\boxed{y = \beta_0 + \beta_1x + \beta_2x^2}$$

یا:

$$y = \beta_0 + \beta_1x + \beta_2x^2 + \beta_3x^3$$

12. نکته بسیار مهم

Polynomial Regression در واقع:

هنوز Linear Model است.

چرا؟

چون نسبت به parameters خطی است:

y = β₀ + β₁x + β₂x²

Features nonlinear شده‌اند، اما coefficients خطی هستند.

13. مشکل Polynomial Regression

اگر degree زیاد شود:

degree ↑

آنگاه:

Complexity ↑ Bias ↓ Variance ↑

و ممکن است:

Overfitting

رخ دهد.

14. Polynomial Explosion

با \(p\) feature و degree \(d\)، تعداد polynomial features می‌تواند بسیار زیاد شود.

خصوصاً interaction terms.

مثلاً:

x1 x2 x1² x2² x1*x2 x1³ x2³ x1²*x2 x1*x2² ...

پس:

Curse of Dimensionality / computational cost

مهم می‌شود.

15. Ridge Regression

Ridge همان Linear Regression با:

L2

است.

$$\boxed{J(\beta) = MSE + \lambda\sum_j\beta_j^2}$$

هدف:

جلوگیری از coefficientهای بسیار بزرگ.

16. Ridge چه زمانی عالی است؟

وقتی:

Features زیاد + Features correlated

داریم.

Ridge معمولاً coefficients را:

→ 0

shrink می‌کند، ولی اغلب دقیقاً صفر نمی‌کند.

17. Ridge و Multicollinearity

فرض کن:

x1 ── correlation ── x2

L2 تمایل دارد اثر را بین آن‌ها توزیع کند.

این یکی از دلایلی است که Ridge برای correlated predictors مناسب است.

18. Lasso

Lasso:

$$\boxed{J(\beta) = MSE + \lambda\sum_j|\beta_j|}$$

است.

L1 باعث:

$$\beta_j = 0$$

برای برخی features می‌شود.

پس:

Feature Selection

انجام می‌دهد.

19. Lasso چه زمانی مفید است؟

وقتی:

p بسیار بزرگ + بسیاری از features احتمالاً irrelevant

داریم.

مثلاً:

10000 features 50 useful

Lasso می‌تواند solution sparse ایجاد کند.

20. مشکل Lasso

با correlated features:

x1 ≈ x2 ≈ x3

ممکن است یکی را نگه دارد و بقیه را حذف کند.

انتخاب ممکن است ناپایدار باشد.

21. Elastic Net

ترکیب:

L1 + L2

است:

$$\boxed{J = MSE + \lambda[\alpha||\beta||_1 + (1-\alpha)||\beta||_2^2]}$$

مزیت:

L1 → sparsity L2 → stability with correlated features

22. Logistic Regression

با وجود اسمش:

Logistic Regression یک Classification Algorithm است.

برای binary classification:

$$z = w^Tx + b$$

و:

$$\boxed{p(y=1|x) = \sigma(z)}$$

که:

$$\sigma(z) = \frac{1}{1+e^{-z}}$$

است.

23. چرا Sigmoid؟

Sigmoid:

$$(-\infty, +\infty) \rightarrow (0,1)$$

تبدیل می‌کند.

پس می‌توانیم probability تفسیر کنیم.

24. Logistic Regression

اگر:

$$p = P(y=1|x)$$

باشد:

$$\boxed{\log\frac{p}{1-p} = w^Tx + b}$$

یعنی Logistic Regression در:

log-odds space

رابطه خطی دارد.

25. Loss

معمولاً:

Binary Cross Entropy / Log Loss

است:

$$\boxed{L = -[y\log p + (1-y)\log(1-p)]}$$

26. Decision Boundary

اگر threshold:

0.5

باشد:

$$p \geq 0.5 \Rightarrow y = 1$$

چون:

$$\sigma(z) = 0.5$$

وقتی:

$$z = 0$$

پس decision boundary:

$$\boxed{w^Tx + b = 0}$$

است.

27. Logistic Regression Linear است؟

بله.

Decision Boundary آن در فضای Feature:

Linear

است.

ولی Probability output nonlinear است.

این distinction خیلی مهم است.

28. Regularized Logistic Regression

می‌توان:

$$L + \lambda||w||_2^2$$

یا:

$$L + \lambda||w||_1$$

داشت.

در عمل این مدل بسیار قوی و underrated است.

بخش دوم — Distance-Based

29. KNN

K-Nearest Neighbors یک:

Instance-Based / Lazy Learning

algorithm است.

Training تقریباً:

فقط ذخیره کردن داده

است.

30. KNN چگونه prediction می‌کند؟

برای نمونه جدید:

New Point │ ▼ Calculate distances │ ▼ Find K nearest samples │ ▼ Vote / Average

Classification:

$$\hat{y} = mode(neighbors)$$

Regression:

$$\hat{y} = average(neighbors)$$

31. چرا K مهم است؟

اگر:

$$K = 1$$

مدل بسیار local است.

Bias ↓ Variance ↑

اگر:

$$K$$

بزرگ شود:

Bias ↑ Variance ↓

پس K خودش یک Bias-Variance hyperparameter است.

32. KNN و Scaling

بسیار مهم.

فرض کن:

Age = 20–80 Salary = 10,000–1,000,000

Euclidean distance تقریباً تحت domination Salary قرار می‌گیرد.

پس معمولاً:

Scaling

ضروری است.

33. Complexity KNN

Training:

تقریباً:

$$O(1)$$

از نظر fitting ساده است.

اما inference:

$$O(nd)$$

برای brute-force، برای هر query.

اگر:

\(n\): تعداد samples \(d\): تعداد features

باشد.

پس KNN:

Training cheap, inference expensive

است.

34. Curse of Dimensionality در KNN

در ابعاد بالا:

فاصله‌ها کمتر meaningful می‌شوند.

ممکن است:

Nearest distance ≈ Farthest distance

شود.

در نتیجه KNN در high-dimensional space ممکن است ضعیف شود.

35. K-Means

K-Means یک:

Unsupervised Clustering Algorithm

است.

هدف:

$$\boxed{\min \sum_{i=1}^{n} ||x_i - \mu_{c_i}||^2}$$

است.

یعنی هر نقطه را به نزدیک‌ترین centroid نسبت می‌دهیم.

36. الگوریتم K-Means

Initialize K centroids ↓ Assign points ↓ Update centroids ↓ Repeat ↓ Converge

37. K-Means چرا Local Minimum دارد؟

K-Means objective غیر-convex نسبت به assignments و centroids به صورت joint است.

پس initialization مهم است.

به همین دلیل:

K-Means++

استفاده می‌شود.

38. K-Means++

Centroidهای اولیه را هوشمندتر انتخاب می‌کند تا احتمال initialization بد کاهش یابد.

39. انتخاب K

روش‌های رایج:

Elbow Method

Plot:

$$Inertia$$

در مقابل K.

Silhouette Score

می‌تواند quality clustering را بررسی کند.

اما:

هیچ‌کدام تضمین نمی‌کنند K واقعی کسب‌وکار را پیدا کرده‌ایم.

40. فرض مهم K-Means

K-Means عمدتاً برای clusterهایی مناسب است که:

compact roughly spherical مشابه از نظر scale

باشند.

برای:

moons rings complex shapes

ممکن است ضعیف باشد.

41. K-Means به Outlier حساس است

Centroid:

$$mean$$

است.

Mean نسبت به outlier حساس است.

مثلاً:

1, 2, 3, 4, 1000

Centroid شدیداً جابه‌جا می‌شود.

42. K-Medoids

K-Medoids شبیه K-Means است، ولی:

centroid باید یکی از داده‌های واقعی باشد.

Medoid:

Actual Data Point

است.

43. مزیت K-Medoids

چون از actual observations استفاده می‌کند و می‌توان از distanceهای generalتر استفاده کرد، معمولاً:

Robustتر نسبت به K-Means

است.

مثلاً برای داده‌هایی که outlier دارند.

45. Decision Tree

Decision Tree داده را با:

سؤال‌های متوالی

تقسیم می‌کند.

مثلاً:

Income > 50K? / \ Yes No / \ Age > 30? Reject / \ Yes No | | Approve Reject

46. Split چگونه انتخاب می‌شود؟

برای Classification معیارهای رایج:

Gini Impurity
$$\boxed{Gini = 1 - \sum_k p_k^2}$$
Entropy
$$\boxed{H = -\sum_k p_k \log p_k}$$

47. Information Gain

$$\boxed{IG = H(parent) - \sum_j \frac{n_j}{n} H(child_j)}$$

Splitی را انتخاب می‌کنیم که impurity را بیشتر کاهش دهد.

48. Regression Tree

MSE / variance

مدنظر است.

49. مزایای Decision Tree

nonlinear interactionها را خودکار یاد می‌گیرد scaling معمولاً لازم نیست interpretability خوب categorical/ordinal data را در برخی implementations خوب مدیریت می‌کند feature engineering کمتر

50. مشکل Decision Tree

اگر بدون محدودیت رشد کند:

$$depth \uparrow$$

Training Error → تقریباً 0 Validation Error → بالا

52. Random Forest

Random Forest:

Ensemble of Decision Trees

است.

Random Forest نوعی:

Bagging

Random Forest فقط sampleها را random نمی‌کند.

بررسی می‌شود.

این باعث کاهش correlation بین trees می‌شود.

55. چرا Ensemble بهتر می‌شود؟

$$Variance$$

$$\boxed{Variance_{ensemble} < Variance_{single\ tree}}$$

56. Random Forest vs Decision Tree

Decision Tree Bias ↓ Variance ↑ Random Forest Bias کمی ↑ Variance ↓↓↓

این دقیقاً یکی از کاربردهای مهم:

Bias–Variance Tradeoff

است.

57. Extra Trees

Extra Trees:

Extremely Randomized Trees

است.

شباهت زیادی به Random Forest دارد، اما randomness بیشتری وارد split selection می‌کند.

58. تفاوت Random Forest و Extra Trees

به صورت مفهومی:

Random Forest

برای splitها:

thresholdهای candidate بر اساس داده بررسی می‌شوند.
Extra Trees

thresholdها را randomتر انتخاب می‌کند.

این randomness بیشتر می‌تواند:

$$Variance \downarrow$$

کند، ولی ممکن است:

$$Bias \uparrow$$

شود.

59. Gradient Boosting

اینجا وارد خانواده بسیار مهمی می‌شویم.

Boosting بر خلاف Bagging:

trees را sequentially می‌سازد.
Tree 1 ↓ Errors ↓ Tree 2 ↓ Remaining errors ↓ Tree 3 ↓ ...

60. ایده Gradient Boosting

فرض کن مدل فعلی:

$$F_{m-1}(x)$$

است.

یک weak learner جدید \(h_m(x)\) اضافه می‌کنیم:

$$\boxed{F_m(x) = F_{m-1}(x) + \eta h_m(x)}$$

که:

$$\eta$$

learning rate است.

61. چرا اسمش Gradient Boosting است؟

در هر مرحله، مدل جدید سعی می‌کند در جهت:

$$-\nabla_F L$$

حرکت کند.

یعنی تقریباً:

Negative Gradient of Loss

را fit می‌کند.

این یک نکته خیلی مهم برای Senior است.

62. Learning Rate در Boosting

اگر:

$$\eta$$

کوچک باشد:

Learning slow Trees needed ↑ Often generalization better

اگر زیاد باشد:

Learning fast Overfitting risk ↑

پس معمولاً:

$$learning\ rate \downarrow \Rightarrow n\_estimators \uparrow$$

یک trade-off رایج است.

63. XGBoost

XGBoost:

Extreme Gradient Boosting

است.

یک implementation بسیار optimized از gradient boosting با regularization و engineering قوی.

64. Objective در XGBoost

به صورت کلی:

$$\boxed{Obj = \sum_i L(y_i, \hat{y}_i) + \sum_k \Omega(f_k)}$$

یعنی:

Training Loss + Model Complexity Penalty

65. Regularization در XGBoost

برای tree complexity پارامترهایی مانند:

gamma max_depth min_child_weight lambda alpha

مهم هستند.

66. XGBoost و Second-Order Information

XGBoost از:

Gradient + Hessian

برای optimization استفاده می‌کند.

تقریب Taylor:

$$L(y, \hat{y} + f) \approx L(y, \hat{y}) + gf + \frac{1}{2}hf^2$$

که:

\(g\): first derivative \(h\): second derivative

است.

این یکی از تفاوت‌های مهم آن با توضیح ساده Gradient Boosting است.

67. XGBoost چرا محبوب است؟

performance قوی regularization handling missing values parallelization mature ecosystem good tabular performance

68. LightGBM

LightGBM نیز Gradient Boosting بر پایه Decision Trees است.

اما design آن برای:

سرعت و مقیاس‌پذیری بالا

بسیار مهم است.

69. مهم‌ترین تفاوت LightGBM

LightGBM از:

Histogram-based algorithms

استفاده می‌کند.

Feature values را به bins تبدیل می‌کند.

به جای:

bins

70. Leaf-wise Growth

این یکی از مهم‌ترین تفاوت‌های LightGBM است.

بسیاری از tree boostingها رشد:

level-wise

دارند.

LightGBM معمولاً:

رشد می‌کند.

یعنی leafای را split می‌کند که بیشترین reduction در loss را ایجاد کند.

71. مزیت Leaf-wise

می‌تواند با تعداد split مشابه:

loss را سریع‌تر کاهش دهد.

اما:

Overfitting risk

بیشتر می‌شود، مخصوصاً روی datasets کوچک.

به همین دلیل:

و:

$$num\_leaves$$

مهم هستند.

Categorical Features

اگر داده کاملاً separable باشد:

103. Gaussian Mixture Model — GMM

GMM یک:

Probabilistic Clustering Model

است.

فرض می‌کند داده از ترکیب چند Gaussian ایجاد شده:

$$\boxed{p(x) = \sum_{k=1}^{K} \pi_k \mathcal{N}(x|\mu_k, \Sigma_k)}$$

که:

$$\sum_k \pi_k = 1$$
