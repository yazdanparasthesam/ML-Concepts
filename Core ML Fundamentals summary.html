🧠 Core ML Fundamentals — Senior Level

بله. اگر منظورت از «موارد این‌مدلی» مفاهیم Fundamental / Core ML Concepts است که مثل Bias–Variance در مصاحبه‌ها و درک عمیق ML خیلی مهم‌اند، یک نقشه‌ی نسبتاً کامل این‌هاست:

🧠 1. مفاهیم پایه‌ی یادگیری

1. Bias–Variance Tradeoff
  • High Bias → Underfitting
  • High Variance → Overfitting
  • هدف: بهترین Generalization
2. Underfitting vs Overfitting
Underfitting:
Train Error ↑ Validation Error ↑
Overfitting:
Train Error ↓ Validation Error ↑
Good Fit:
Train Error ↓ Validation Error ↓
3. Generalization

مدل باید روی داده‌هایی که قبلاً ندیده خوب عمل کند.

Training Data ↓ Model ↓ Unseen Data ↓ Generalization

این در واقع یکی از اهداف اصلی ML است.

4. Empirical Risk vs Expected Risk
Empirical Risk:

خطایی که روی Training Data اندازه می‌گیریم:

$$R_{emp}(f) = \frac{1}{n} \sum_{i=1}^{n} L(f(x_i), y_i)$$
Expected Risk:

خطایی که انتظار داریم روی کل Distribution داده داشته باشیم:

$$R(f) = E[L(f(X), Y)]$$

ما در عمل Expected Risk را مستقیماً نمی‌دانیم؛ بنابراین با Empirical Risk آن را تخمین می‌زنیم.

⚖️ 5. Model Complexity

هرچه مدل پیچیده‌تر شود معمولاً:

Complexity ↑ ↓ Bias ↓ Variance ↑

مثلاً:

Linear Regression ↓ Polynomial Regression ↓ Decision Tree ↓ Deep Neural Network

اما این رابطه همیشه به شکل کلاسیک و ساده نیست؛ مخصوصاً در Deep Learning.

🎯 6. Train / Validation / Test

این سه تا را باید کاملاً بلد باشی.

Train

برای یادگیری Parameters:

w, b
Validation

برای انتخاب:

Hyperparameters Model Threshold Architecture
Test

برای Final Evaluation.

مثلاً:

70% Train 15% Validation 15% Test

نکته مهم:

Test Set نباید برای تصمیم‌گیری مکرر استفاده شود.
🔧 7. Parameters vs Hyperparameters
Parameters

مدل خودش یاد می‌گیرد:

Weights Biases

مثلاً:

$$y = wx + b$$

w و b پارامترند.

Hyperparameters

ما تعیین می‌کنیم:

Learning Rate Tree Depth Number of Trees Batch Size Regularization λ Number of Layers
📉 8. Loss Function vs Evaluation Metric

خیلی مهم.

Loss

برای Training / Optimization استفاده می‌شود.

مثلاً:

$$MSE = \frac{1}{n} \sum (y - \hat{y})^2$$
Metric

برای ارزیابی عملکرد استفاده می‌شود.

مثلاً:

Accuracy Precision Recall F1 AUC MAE RMSE R²

ممکن است Loss و Metric یکی نباشند.

🔥 9. Optimization vs Generalization

مدل دو مسئله متفاوت دارد:

Optimization

آیا توانسته‌ایم Loss روی Training را کم کنیم؟

Generalization

آیا مدل روی داده جدید هم خوب عمل می‌کند؟

ممکن است:

Training Loss = Excellent Generalization = Poor

که همان Overfitting است.

🧮 10. Bias–Variance Decomposition

برای Regression با Squared Error، به صورت مفهومی:

$$Expected Error = Bias^2 + Variance + Noise$$

یعنی:

Total Error = Bias² + Variance + Irreducible Noise
Irreducible Noise

خطایی که حتی بهترین مدل هم نمی‌تواند حذف کند.

مثلاً:

Measurement Error Randomness Missing Information
🎲 11. Aleatoric vs Epistemic Uncertainty

این یکی خیلی مهم و Advanced است.

Aleatoric Uncertainty

عدم قطعیت ذاتی در داده.

مثلاً:

دو خانه کاملاً مشابه ولی قیمت‌های متفاوت

این randomness ممکن است قابل حذف نباشد.

Epistemic Uncertainty

عدم قطعیت ناشی از این‌که مدل اطلاعات کافی ندارد.

مثلاً مدل فقط خانه‌های تهران را دیده و حالا باید قیمت یک خانه در شهری کاملاً جدید را پیش‌بینی کند.

More Data ↓ Epistemic Uncertainty ↓
📊 12. Data Leakage

یکی از مهم‌ترین مفاهیم ML Engineering.

یعنی اطلاعاتی از آینده یا Test وارد Training شود.

مثلاً:

Normalize whole dataset ↓ Train/Test Split

اشتباه.

باید:

Train/Test Split ↓ Fit scaler on Train ↓ Transform Train ↓ Transform Test

مثال دیگر:

Future information ↓ Training Features

این باعث Validation/Test Performance غیرواقعی می‌شود.

🔀 13. IID Assumption

بسیاری از الگوریتم‌های ML فرض می‌کنند داده‌ها تقریباً:

Independent and Identically Distributed

هستند.

یعنی:

Independent + Same Distribution

ولی در Time Series معمولاً:

Past → Future

وابستگی وجود دارد.

بنابراین Random Shuffle می‌تواند مشکل‌ساز شود.

🌍 14. Covariate Shift

Distribution Featureها تغییر می‌کند:

$$P_{train}(X) \neq P_{test}(X)$$

ولی:

$$P(Y|X)$$

تقریباً ثابت می‌ماند.

مثلاً مدل روی کاربران قدیمی آموزش دیده و کاربران جدید ویژگی‌های متفاوتی دارند.

🔄 15. Concept Drift

رابطه بین X و Y تغییر می‌کند:

$$P_{train}(Y|X) \neq P_{production}(Y|X)$$

مثلاً:

Fraud Pattern ↓ 2024 ↓ Different ↓ 2026

مدلی که قبلاً خوب بوده ممکن است به مرور خراب شود.

🧩 16. Class Imbalance

مثلاً:

Normal: 99% Fraud: 1%

اگر مدل همیشه Normal بگوید:

Accuracy = 99%

ولی عملاً مدل Fraud Detection بدی است.

پس باید برویم سراغ:

Precision Recall F1 PR-AUC ROC-AUC Confusion Matrix
🎚️ 17. Threshold Tradeoff

در Classification خروجی مدل ممکن است Probability باشد:

P(Fraud) = 0.72

اگر:

Threshold = 0.5

→ Fraud

ولی اگر:

Threshold = 0.8

→ Normal

تغییر Threshold باعث تغییر:

Precision ↔ Recall

می‌شود.

🔺 18. ROC vs PR
ROC Curve

بین:

TPR FPR
PR Curve

بین:

Precision Recall

برای Imbalanced Classification معمولاً PR-AUC اطلاعات مفیدتری درباره عملکرد روی کلاس مثبت می‌دهد.

🧠 19. Calibration

مدل ممکن است Probability بدهد:

P(Fraud) = 0.8

Calibration می‌پرسد:

آیا واقعاً تقریباً 80٪ نمونه‌هایی که مدل Probability=0.8 داده Fraud هستند؟

ممکن است:

Accuracy = Excellent Calibration = Poor

دو مفهوم متفاوت‌اند.

🌳 20. Bagging vs Boosting
Bagging

مدل‌ها بیشتر به صورت موازی ساخته می‌شوند.

مثال:

Random Forest

هدف اصلی:

Variance ↓
Boosting

مدل‌ها sequential ساخته می‌شوند.

مثال:

XGBoost LightGBM CatBoost

به طور مفهومی بیشتر برای کاهش Bias و ساخت مدل قوی استفاده می‌شود، هرچند رفتار واقعی به تنظیمات و داده بستگی دارد.

🧮 21. Parametric vs Non-Parametric
Parametric

ساختار پارامترها نسبتاً مشخص است.

مثلاً:

Linear Regression
Non-Parametric

تعداد/ساختار مؤثر پارامترها می‌تواند با داده رشد کند.

مثلاً:

KNN Decision Tree
📐 22. Generative vs Discriminative
Discriminative

مستقیماً رابطه تصمیم را یاد می‌گیرد:

$$P(Y|X)$$

مثلاً:

Logistic Regression SVM Neural Network Classifier
Generative

Distribution داده را مدل می‌کند.

مثلاً:

$$P(X,Y)$$

و از آن می‌تواند:

$$P(Y|X)$$

را به دست آورد.

مثال:

Naive Bayes Gaussian Mixture Model
🔍 23. Feature Selection vs Feature Extraction
Feature Selection

از Featureهای موجود بعضی را حذف می‌کنیم.

F1 F2 F3 F4 F5 ↓ F1 F3 F5
Feature Extraction

Feature جدید می‌سازیم.

مثلاً:

PCA 100 Features ↓ PCA ↓ 10 Components
📏 24. Normalization vs Standardization
Standardization
$$z = \frac{x - \mu}{\sigma}$$

تقریباً:

Mean = 0 Std = 1
Min-Max Normalization
$$x' = \frac{x - min(x)}{max(x) - min(x)}$$

تقریباً:

0 ≤ x' ≤ 1

این موضوع مخصوصاً برای:

Neural Networks KNN SVM PCA Gradient Descent

مهم است.

📉 25. Curse of Dimensionality

هرچه تعداد Featureها زیاد شود، فضا sparseتر می‌شود.

Dimensions ↑ ↓ Data Sparsity ↑ ↓ Distance becomes less informative ↓ ML Performance may ↓

برای همین:

Feature Selection PCA Regularization More Data

مهم می‌شوند.

🧠 26. VC Dimension

یک مفهوم تئوری مهم برای ظرفیت مدل.

به صورت ساده:

VC Dimension نشان می‌دهد یک مدل چقدر توانایی fit کردن الگوهای مختلف را دارد.

ظرفیت بیشتر:

Model Capacity ↑

می‌تواند باعث شود مدل الگوهای پیچیده‌تری را یاد بگیرد؛ ولی ریسک Generalization هم باید تحلیل شود.

🧠 27. No Free Lunch Theorem

هیچ الگوریتمی وجود ندارد که برای تمام مسائل بهترین باشد.

یعنی:

XGBoost ≠ Best for Everything

انتخاب مدل به:

Data Distribution Noise Feature Type Objective Constraints

وابسته است.

🧪 28. Cross Validation

به جای یک Train/Validation Split:

Fold 1 Fold 2 Fold 3 Fold 4 Fold 5

مدل را چند بار ارزیابی می‌کنیم.

مثلاً:

Fold CV-5
$$CV Score = \frac{1}{5} \sum Score_i$$

مزیت:

تخمین robustتر از Generalization Performance.
🔁 29. Nested Cross Validation

برای Hyperparameter Tuning جدی‌تر.

Outer CV ↓ Performance Evaluation Inner CV ↓ Hyperparameter Tuning

کمک می‌کند bias ناشی از انتخاب مدل/Hyperparameter را در ارزیابی نهایی کاهش دهیم.

🎯 30. Regularization

دو نوع معروف:

L1
$$Loss + \lambda \sum |w_i|$$

تمایل به:

Sparse Weights

و Feature Selection دارد.

L2
$$Loss + \lambda \sum w_i^2$$

وزن‌ها را کوچک‌تر می‌کند.

🧠 31. Early Stopping

در Neural Network:

Epoch ↓ Train Loss ↓ Validation Loss ↓ ↓ ↓ ↑ │ Overfitting starts

در نقطه مناسب Training را متوقف می‌کنیم.

🎲 32. Ensemble Learning

به جای یک مدل:

Model 1 Model 2 Model 3 Model 4 ↓ Combine ↓ Final Prediction

مثال:

Random Forest XGBoost Voting Stacking Bagging Boosting

هدف معمولاً کاهش خطا و بهبود Generalization است.

⚠️ 33. Simpson's Paradox

یک رابطه ممکن است:

Overall Dataset → Positive

ولی وقتی داده را Group کنیم:

Group A → Negative Group B → Negative

باشد.

این موضوع در:

Statistics ML Data Analysis

خیلی مهم است.

🔗 34. Correlation vs Causation

ML معمولاً:

Correlation

را یاد می‌گیرد، نه لزوماً:

Causation

مثلاً:

Ice Cream Sales ↑ Drowning ↑

به این معنی نیست که Ice Cream باعث غرق شدن شده.

عامل سوم:

Temperature ↑

است.

💥 35. Spurious Correlation

مدل ممکن است یک رابطه تصادفی را به عنوان Pattern یاد بگیرد.

Feature ↓ Accidental Correlation ↓ Model learns it ↓ Fails on new data

این یکی از دلایل Overfitting است.

🧠 36. Distribution Shift

یک مفهوم کلی‌تر:

$$P_{train}(X,Y) \neq P_{production}(X,Y)$$

انواع مهم:

Covariate Shift Label Shift Concept Drift

این موضوع برای Production ML فوق‌العاده مهم است.

🚨 37. Selection Bias

داده‌ای که جمع کرده‌ایم نماینده واقعی Population نیست.

مثلاً فقط از:

Tech Users

داده بگیریم و بعد مدل را برای:

All Users

استفاده کنیم.

🕳️ 38. Missing Data Mechanisms

سه مفهوم مهم:

MCAR

Missing Completely At Random

MAR

Missing At Random

MNAR

Missing Not At Random

نحوه Missing شدن Data می‌تواند روی انتخاب روش Imputation اثر بگذارد.

🔥 39. Data Quantity vs Data Quality

همیشه:

More Data ≠ Better Data

ممکن است:

1M noisy samples

بدتر از:

100K high-quality samples

باشد.

⚔️ 40. Bias in Dataset vs Bias in Model

این دو را قاطی نکن.

Statistical Bias

مفهوم آماری مربوط به Error.

Dataset Bias

مشکل در نحوه جمع‌آوری/نمایندگی داده.

Algorithmic Bias

رفتار نامطلوب مدل نسبت به گروه‌ها یا شرایط خاص.

این‌ها مفاهیم متفاوتی هستند.
