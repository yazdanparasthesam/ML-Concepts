🚀 11. Ensemble Learning

حتماً. این بخش یعنی Ensemble Learning یکی از مهم‌ترین مباحث Senior ML است؛ چون تقریباً تمام خانواده‌های قدرتمند مدل‌های کلاسیک مثل Random Forest، XGBoost، LightGBM و CatBoost از همین ایده‌ها می‌آیند.

نکته کلیدی این فصل این است:

به‌جای اینکه روی یک مدل واحد تکیه کنیم، چند مدل را طوری ترکیب می‌کنیم که نقاط ضعف یکدیگر را جبران کنند.

1. Ensemble Learning چیست؟

فرض کن یک مدل داریم:

$$Model A \rightarrow Prediction$$

به‌جای آن:

Model A ─┐ Model B ─┤ Model C ─┼──→ Ensemble → Final Prediction Model D ─┘

استفاده می‌کنیم.

ایده اصلی:

$$Multiple Models \rightarrow Combined Prediction$$
⚠️ اما نکته مهم:

صرفاً زیاد کردن تعداد مدل‌ها Ensemble خوب نمی‌سازد.

دو چیز بسیار مهم‌اند:

  • قدرت مدل‌ها
  • تنوع خطاهای مدل‌ها

2. چرا Ensemble کار می‌کند؟

فرض کن سه classifier داریم. برای یک sample:

Model A → Fraud Model B → Legit Model C → Fraud

Voting می‌گوید:

$$Fraud$$

اما مسئله عمیق‌تر از majority vote است.

اگر مدل‌ها اشتباه‌های کاملاً مشابهی داشته باشند:

Model A → wrong Model B → wrong Model C → wrong

Ensemble فایده زیادی ندارد.

پس:

$$Good Ensemble = Strong Models + Diversity$$

3. دو هدف اصلی Ensemble

در لیست شما دو مفهوم بسیار مهم داریم:

Variance Reduction

و:

Bias Reduction

تقریباً تمام Ensemble methods را می‌توان با این دو مفهوم تحلیل کرد.

4. Bias Reduction

Bias یعنی مدل چقدر از الگوی واقعی ساده‌سازی شده فاصله دارد.

مدل high-bias معمولاً:

  • بیش از حد ساده است.

مثلاً:

Linear Model

برای یک رابطه کاملاً nonlinear.

در این حالت:

Training error ↑ Validation error ↑

است.

5. Variance Reduction

Variance یعنی مدل چقدر به dataset خاص حساس است.

مدلی مثل:

Deep Decision Tree

ممکن است:

Training error ≈ 0

ولی با تغییر کوچک در training data، ساختارش کاملاً تغییر کند.

یعنی:

Variance ↑

6. Ensemble و Bias-Variance

این رابطه را خیلی خوب بلد باش:

High Bias ↓ Underfitting ↓ Need more expressive model ↓ Bias Reduction
High Variance ↓ Overfitting ↓ Need averaging / regularization ↓ Variance Reduction

7. Bagging

Bagging مخفف:

$$Bootstrap Aggregating$$

ایده:

Original Dataset │ ├── Bootstrap Sample 1 → Model 1 ├── Bootstrap Sample 2 → Model 2 ├── Bootstrap Sample 3 → Model 3 ├── Bootstrap Sample 4 → Model 4 └── Bootstrap Sample N → Model N │ ▼ Aggregate

8. Bootstrap Sampling چیست؟

فرض کن:

Dataset = 100 samples

یک bootstrap sample با:

$$Sampling\ with\ replacement$$

ساخته می‌شود.

یعنی ممکن است:

Sample 1 Sample 5 Sample 5 Sample 17 Sample 23 Sample 23 ...

داشته باشیم.

9. چرا Sampling With Replacement؟

چون باعث می‌شود هر model dataset کمی متفاوتی ببیند.

در نتیجه:

Model 1 → slightly different Model 2 → slightly different Model 3 → slightly different

و این diversity ایجاد می‌کند.

10. Aggregation در Bagging

برای Regression:

$$\hat{y} = \frac{1}{B} \sum_{b=1}^B \hat{y}_b$$

یعنی:

Average predictions.

برای Classification معمولاً:

$$Majority\ voting$$

انجام می‌شود.

11. چرا Bagging Variance را کم می‌کند؟

فرض کن predictionهای چند model داریم.

اگر errorهای آنها تا حدی مستقل باشند، averaging باعث می‌شود خطاهای تصادفی یکدیگر را خنثی کنند.

برای مدل‌های با واریانس σ² و تقریباً independent:

$$Var(\bar{X}) = \frac{\sigma^2}{B}$$

پس:

$$B \uparrow \Rightarrow Variance \downarrow$$

البته در دنیای واقعی مدل‌ها کاملاً مستقل نیستند.

12. Correlation بین Models

اگر predictions مدل‌ها correlated باشند، کاهش variance کمتر می‌شود.

به‌صورت مفهومی:

$$Var(\bar{X})$$

به correlation بین modelها وابسته است.

پس:

$$Lower Correlation \rightarrow Better Variance Reduction$$

این یکی از مهم‌ترین مفاهیم Ensemble است.

13. Bagging بیشتر برای چه چیزی خوب است؟

Bagging مخصوصاً برای:

$$High-Variance Learners$$

خوب است.

مثلاً:

Decision Tree

که variance بالایی دارد.

14. Random Forest

Random Forest را می‌توان تقریباً این‌طور دید:

$$Random Forest = Bagging + Random Feature Selection$$

یعنی دو نوع randomness داریم:

1. Random Samples Bootstrap sampling. 2. Random Features در هر split فقط subsetی از features بررسی می‌شود.

15. ساخت Random Forest

فرض کن:

10,000 samples 100 features

داریم.

Random Forest:

Bootstrap dataset ↓ Build Tree 1 ↓ At each split: random subset of features

و همین برای Treeهای متعدد.

16. چرا Random Feature Selection مهم است؟

فرض کن:

X1

خیلی feature قوی‌ای است.

اگر همه treeها همیشه آن را ببینند:

Tree 1 → X1 Tree 2 → X1 Tree 3 → X1 Tree 4 → X1

treeها شبیه هم می‌شوند.

پس:

$$Correlation \uparrow$$

و مزیت averaging کاهش می‌یابد.

17. Random Forest چگونه Variance را کم می‌کند؟

Deep Tree ↓ High Variance ↓ Many Trees + Randomization ↓ Averaging ↓ Variance ↓

در حالت ایده‌آل:

$$Variance \downarrow$$

بدون اینکه bias به اندازه‌ای که یک درخت ساده‌تر ایجاد می‌کند افزایش پیدا کند.

18. آیا Random Forest Bias را کاهش می‌دهد؟

هدف اصلی Random Forest:

$$Variance Reduction$$

است.

ولی در عمل ممکن است با تنظیمات مناسب عملکرد کلی را بهتر کند.

پس در مصاحبه بهتر است بگویی:

Random Forest primarily reduces variance by averaging decorrelated high-variance trees.

19. Out-of-Bag Samples

یک نکته Senior بسیار مهم:

در bootstrap sampling، همه samples وارد هر tree نمی‌شوند.

تقریباً:

$$63.2\%$$

از unique samples در هر bootstrap sample حضور دارند.

حدود:

$$36.8\%$$

برای آن tree خارج از bootstrap می‌مانند.

به این‌ها می‌گوییم:

$$Out-of-Bag samples — OOB$$

20. OOB Evaluation

می‌توان از OOB samples برای تخمین performance استفاده کرد.

یعنی:

Bootstrap sample ↓ Train Tree OOB samples ↓ Evaluate Tree

و aggregation روی predictionهای مربوطه انجام می‌شود.

مزیت:

در بعضی کاربردها بدون نیاز به validation set جداگانه می‌توان تخمین performance داشت.

اما OOB جایگزین validation/test برای همه سناریوها نیست.

21. Bagging vs Random Forest

Featuresالزاماً feature randomness نداردFeature randomness دارد

22. Boosting

حالا به خانواده کاملاً متفاوتی می‌رسیم.

Bagging: Models → Parallel / Independent

اما Boosting:

Model 1 ↓ Model 2 ↓ Model 3 ↓ Model 4

مدل‌ها:

$$Sequentially$$

ساخته می‌شوند.

23. ایده اصلی Boosting

هر model تلاش می‌کند:

اشتباهات قبلی را اصلاح کند.

مثلاً:

Model 1 ↓ Residuals / Errors ↓ Model 2 learns them ↓ Remaining errors ↓ Model 3

24. Bagging vs Boosting

این تفاوت را حتماً حفظ کن:

BaggingBoosting
TrainingمستقلSequential
هدف اصلیVariance reductionBias reduction
مثالRandom ForestXGBoost
Base learnersمعمولاً strong/high varianceمعمولاً weak learners
Parallelizationآسان‌ترذاتاً sequential
Overfittingکمتر مستعدنیازمند regularization

25. AdaBoost

AdaBoost یکی از اولین الگوریتم‌های مهم Boosting است.

ایده:

به نمونه‌هایی که اشتباه classify شده‌اند وزن بیشتری بده.

26. AdaBoost

ابتدا:

All samples ↓ Equal weights

بعد model اول ساخته می‌شود.

نمونه‌های اشتباه:

Wrong samples ↓ Higher weight

Model بعدی بیشتر روی آنها تمرکز می‌کند.

27. ساختار AdaBoost

Samples ↓ Equal weights ↓ Weak Learner 1 ↓ Increase weight of mistakes ↓ Weak Learner 2 ↓ Increase weight of mistakes ↓ Weak Learner 3 ↓ Weighted combination

28. Weak Learner چیست؟

مدلی که:

کمی بهتر از random guessing

عمل کند.

در AdaBoost معمولاً:

$$Decision Stump$$

رایج است.

Decision Stump:

Tree depth = 1

29. وزن Model در AdaBoost

مدل‌هایی که error کمتری دارند:

وزن بیشتری

در ensemble می‌گیرند.

به صورت کلاسیک:

$$\alpha_t = \frac{1}{2} \ln \left( \frac{1 - \epsilon_t}{\epsilon_t} \right)$$

که:

ε_t

خطای model است.

30. اگر Model خوب باشد؟

اگر:

ε_t ↓

آنگاه:

α_t ↑

پس model وزن بیشتری می‌گیرد.

31. اگر Error = 0.5 باشد؟

برای binary classification:

ε = 0.5

پس:

α = 0

یعنی model اطلاعاتی بهتر از random guessing ندارد.

32. اگر Error > 0.5 باشد؟

در AdaBoost کلاسیک:

مدل بدتر از random guessing است.

روش‌های مختلف می‌توانند handling متفاوتی داشته باشند، اما به‌صورت کلاسیک چنین learnerی مناسب نیست.

33. Gradient Boosting

Gradient Boosting ایده Boosting را generalize می‌کند.

به جای اینکه فقط:

misclassified samples

را دنبال کند، مدل جدید را برای کاهش:

$$Loss Function$$

می‌سازد.

34. ایده Gradient Boosting

فرض کن prediction فعلی:

F(x)

است.

می‌خواهیم:

Loss(y, F(x))

را کاهش دهیم.

Model جدید:

h(x)

را در جهت:

$$-\nabla_F Loss$$

یاد می‌گیریم.

35. چرا اسمش Gradient Boosting است؟

چون مدل‌ها در جهت:

$$Negative Gradient$$

loss حرکت می‌کنند.

شبیه Gradient Descent، اما به جای اینکه مستقیماً parameters یک model را update کنیم، یک learner جدید به ensemble اضافه می‌کنیم.

36. ساخت Gradient Boosting

Initial prediction ↓ Calculate errors / negative gradients ↓ Train weak tree ↓ Add tree to ensemble ↓ Calculate new residuals ↓ Train next tree ↓ ...

37. فرمول Gradient Boosting

به صورت مفهومی:

$$F_m(x) = F_{m-1}(x) + \eta h_m(x)$$

که:

• F_m : model فعلی • h_m : tree جدید • η : learning rate

است.

38. Learning Rate در Boosting

اگر:

η

کوچک باشد:

Each tree contributes little

پس معمولاً:

n_estimators ↑

نیاز داریم.

این یک tradeoff مهم است:

$$Learning Rate \downarrow \Rightarrow More Trees$$

39. XGBoost

XGBoost یعنی:

$$Extreme Gradient Boosting$$

یکی از معروف‌ترین implementationهای Gradient Boosting است.

اما فقط Gradient Boosting ساده نیست.

ویژگی‌های مهم:

• Regularization • Efficient tree construction • Second-order information • Shrinkage • Row subsampling • Column subsampling • Missing value handling • Parallelized operations • Tree pruning

40. Objective در XGBoost

به صورت کلی:

$$Obj = Loss + Regularization$$

یعنی:

$$Obj = \sum_i L(y_i, \hat{y}_i) + \Omega(model)$$

41. Regularization در XGBoost

XGBoost می‌تواند complexity tree را penalize کند.

مثلاً:

• number of leaves • leaf weights

را کنترل می‌کند.

این باعث کاهش:

$$Overfitting$$

می‌شود.

42. First-Order و Second-Order Information

Gradient Boosting ساده عمدتاً از:

g_i

gradient استفاده می‌کند.

XGBoost علاوه بر gradient از:

h_i

Hessian نیز استفاده می‌کند.

یعنی:

$$First Order + Second Order$$

43. چرا Hessian مهم است؟

Hessian اطلاعات curvature loss را می‌دهد.

در نتیجه optimization دقیق‌تر می‌شود.

این یکی از تفاوت‌های مهم نظری XGBoost با Gradient Boosting ساده است.

44. XGBoost چرا محبوب شد؟

چون ترکیبی از:

• Accuracy + Regularization + Speed + Engineering + Flexibility

ارائه می‌دهد.

برای tabular data هنوز یکی از baselineهای بسیار قدرتمند است.

45. LightGBM

LightGBM نیز Gradient Boosting Tree است.

اما architecture و tree-growing strategy متفاوتی دارد.

دو مفهوم مهم:

Histogram-based learning

و:

Leaf-wise tree growth

46. Histogram-based Split

به جای بررسی تمام thresholdهای دقیق، feature values را به bins تبدیل می‌کند.

مثلاً:

0–10 10–20 20–30 30–40 ...

این کار:

$$computational cost$$

را کاهش می‌دهد.

47. Leaf-wise Growth

این تفاوت را خیلی خوب بلد باش.

روش معمول level-wise:

Root / \ A B / \ / \

درخت را level به level رشد می‌دهد.

LightGBM معمولاً:

$$leaf-wise$$

رشد می‌کند.

یعنی:

leafای را split می‌کند که بیشترین gain را دارد.

48. Leaf-wise چه مزیتی دارد؟

می‌تواند سریع‌تر loss را کاهش دهد.

اما:

$$Overfitting risk$$

بیشتر می‌شود، مخصوصاً وقتی dataset کوچک باشد.

به همین دلیل hyperparameterهایی مثل:

• num_leaves • min_data_in_leaf • max_depth

مهم هستند.

49. XGBoost vs LightGBM

XGBoostLightGBM

HistogramHistogram supportHistogram-based

GrowthTree growth معمولاً level-wiseleaf-wise

نکته:

«LightGBM همیشه سریع‌تر و XGBoost همیشه دقیق‌تر است» یک قانون قطعی نیست.

Dataset و hyperparameterها تعیین‌کننده‌اند.

50. CatBoost

CatBoost نیز Gradient Boosting است.

نقطه قوت معروف آن:

$$Categorical Features$$

است.

مثلاً:

city country merchant device_type product

51. مشکل Encoding ساده

فرض کن:

City: Tehran Istanbul Baku

One-hot encoding ممکن است تعداد featureها را زیاد کند.

Label Encoding:

Tehran = 0 Istanbul = 1 Baku = 2

ممکن است ordering مصنوعی ایجاد کند.

CatBoost روش‌های تخصصی‌تری برای categorical features دارد.

52. Target Statistics

CatBoost از ایده:

$$Ordered Target Statistics$$

استفاده می‌کند.

به جای اینکه category را صرفاً عددگذاری کنیم، از اطلاعات target برای representation استفاده می‌شود، اما با روش ordered برای کاهش:

$$Target Leakage$$

53. چرا Ordered مهم است؟

اگر برای یک row از target خودش برای ساخت feature استفاده کنیم:

Target ↓ Feature ↓ Same Target

leakage ایجاد می‌شود.

CatBoost با ordered scheme تلاش می‌کند این مشکل را کاهش دهد.

54. CatBoost و Ordered Boosting

CatBoost همچنین:

$$Ordered Boosting$$

را معرفی می‌کند تا برخی مشکلات prediction shift / leakage-like effects در boosting را کاهش دهد.

این یکی از دلایل robustness آن روی categorical data است.

55. Voting

حالا از Tree Ensembles فاصله بگیریم.

Voting یعنی چند مدل مختلف داریم:

Logistic Regression Random Forest SVM XGBoost

و prediction آنها را ترکیب می‌کنیم.

56. Hard Voting

هر model یک class می‌دهد:

LR → Fraud RF → Legit SVM → Fraud XGBoost → Fraud

Majority:

Fraud

پس:

$$Hard Voting = Majority Vote$$

57. Soft Voting

در Soft Voting به جای class نهایی، probability را ترکیب می‌کنیم.

مثلاً:

LR: Fraud = 0.7 RF: Fraud = 0.8 XGB: Fraud = 0.9

Average:

$$P(Fraud) = \frac{0.7 + 0.8 + 0.9}{3} = 0.8$$

پس:

Fraud

58. Hard vs Soft Voting

Hard VotingSoft Voting
Inputclass labelsprobabilities
Simplicityسادهاطلاعات بیشتر
Calibrationcalibration لازم نیستcalibration مهم است
Methodmajority voteweighted probability aggregation

59. Weighted Voting

لازم نیست همه models وزن یکسان داشته باشند.

مثلاً:

LR weight = 1 RF weight = 2 XGBoost weight = 3

پس:

$$P = \frac{1 \cdot P_{LR} + 2 \cdot P_{RF} + 3 \cdot P_{XGB}}{6}$$

این می‌تواند عملکرد را بهتر کند.

اما وزن‌ها باید:

روی validation data

تنظیم شوند، نه test set.

60. Stacking

Stacking یکی از مهم‌ترین Ensemble methods است.

ساختار:

Model 1 ─┐ Model 2 ─┤ Input Data ── Model 3 ─┼──→ Meta Model → Final Model 4 ─┘

Modelهای اولیه:

$$Base Learners$$

و مدل نهایی:

$$Meta Learner$$

نام دارد.

61. مثال Stacking

Base models:

Random Forest XGBoost SVM Logistic Regression

predictionهای آنها:

0.8 0.7 0.6 0.9

به Meta Model داده می‌شود.

مثلاً:

Logistic Regression

یاد می‌گیرد:

چگونه predictionهای base models را ترکیب کند.

62. مشکل مهم Stacking: Leakage

فرض کن:

Model A

روی training data prediction می‌دهد.

اگر همان prediction را مستقیماً به meta-model بدهیم:

Training data ↓ Model A ↓ Prediction ↓ Meta Model

Model A ممکن است training data را overfit کرده باشد.

پس Meta Model اطلاعات بیش از حد خوش‌بینانه دریافت می‌کند.

63. راه‌حل Stacking: Out-of-Fold Predictions

روش درست:

Training Data │ ├── Fold 1 │ Model trained on Fold 2-5 │ Predict Fold 1 │ ├── Fold 2 │ Model trained on Fold 1,3-5 │ Predict Fold 2 │ └── ...

در نهایت برای هر training sample:

predictionای داریم که از مدلی آمده که آن sample را در training ندیده است.

این:

$$Out-of-Fold Prediction$$

است.

64. Stacking واقعی

Training Data │ ┌────────────┼────────────┐ ▼ ▼ ▼ Model A Model B Model C │ │ │ ▼ ▼ ▼ OOF Pred OOF Pred OOF Pred │ │ │ └────────────┼────────────┘ ▼ Meta Learner │ ▼ Final Prediction

این یکی از نکات بسیار مهم Senior ML است.

65. Stacking در Test

بعد از آموزش:

Base models ↓ Retrain on full training data ↓ Predict test ↓ Meta model ↓ Final prediction

اما باید pipeline کامل بدون leakage طراحی شود.

66. Blending

Blending شبیه Stacking است، اما ساده‌تر.

معمولاً:

Training set │ ├── Train Base Models │ ▼ Holdout Validation Set │ ├── Prediction Model A ├── Prediction Model B └── Prediction Model C │ ▼ Meta Model

به جای K-fold OOF، از:

$$Holdout set$$

برای ساخت meta-features استفاده می‌شود.

67. Stacking vs Blending

StackingBlending
Methodمعمولاً K-fold OOFHoldout validation
Data usageداده بهتر استفاده می‌شودساده‌تر
Complexityپیچیده‌ترساده‌تر
Costcomputational cost بیشترسریع‌تر
Leakageleakage control دقیق‌تروابسته به holdout صحیح

68. Bagging vs Boosting vs Stacking

Bagging Parallel ↓ Variance Reduction Boosting Sequential ↓ Bias Reduction Stacking Different Models ↓ Meta Learner ↓ Learn how to combine

این سه خط را برای مصاحبه حفظ کن.

69. Random Forest vs XGBoost

یکی از سؤال‌های محبوب Senior Interview:

Random Forest Independent Trees + Bootstrap + Random Features + Averaging هدف اصلی: Variance Reduction
XGBoost Sequential Trees + Gradient + Regularization + Learning Rate هدف: Bias Reduction + Optimization

70. چرا Boosting می‌تواند overfit کند؟

چون sequentially می‌تواند بسیار قدرتمند شود.

اگر:

n_estimators ↑ tree depth ↑ learning rate ↑

باشد، model می‌تواند بیش از حد fit شود.

پس boosting نیز regularization می‌خواهد.

71. مهم‌ترین Hyperparameterهای Boosting

n_estimators تعداد trees. learning_rate Contribution هر tree. max_depth پیچیدگی tree. min_child_weight / min_data_in_leaf کنترل leafها. subsample درصد samples. colsample درصد features.

72. Learning Rate و Number of Trees

یکی از tradeoffهای مهم:

learning_rate = 0.3 n_estimators = 100

در مقابل:

learning_rate = 0.03 n_estimators = 1000

ممکن است دومی generalization بهتری داشته باشد، ولی:

$$computational cost$$

بیشتری دارد.

73. Early Stopping در Boosting

یکی از بهترین ابزارهای کنترل overfitting:

Train ↓ Monitor validation loss ↓ Improving? ↓ Yes → Continue No → Stop

مثلاً:

Best iteration = 427

اگر treeها تا 2000 ادامه پیدا کنند، ممکن است overfit شوند.

74. Subsampling در Gradient Boosting

می‌توان در هر iteration فقط بخشی از data را استفاده کرد.

مثلاً:

subsample = 0.8

یعنی حدود 80٪ samples.

این می‌تواند:

$$randomness$$

ایجاد کرده و overfitting را کاهش دهد.

75. Column Subsampling

مشابه Random Forest:

colsample = 0.8

یعنی در هر مرحله فقط subsetی از features استفاده شود.

مزایا:

• diversity • speed • regularization

76. Ensemble Diversity

این موضوع آنقدر مهم است که جداگانه باید حفظ شود.

فرض کن:

Model A accuracy = 90% Model B accuracy = 90% Model C accuracy = 90%

این به تنهایی کافی نیست.

اگر هر سه دقیقاً روی همان samples اشتباه کنند:

A error = E B error = E C error = E

ensemble احتمالاً سود کمی دارد.

77. Diversity چگونه ایجاد می‌شود؟

روش‌های مختلف:

Bagging داده‌های مختلف. Random Forest داده + feature randomness. Boosting focus متفاوت روی errors. Stacking مدل‌های با inductive bias متفاوت.

مثلاً:

Linear + Tree + Kernel + Neural Network

78. Inductive Bias

هر مدل فرض متفاوتی درباره data دارد.

مثلاً:

Linear Regression فرض رابطه تقریباً linear. Decision Tree فرض می‌کند partitionهای feature space مفیدند. KNN فرض می‌کند نمونه‌های نزدیک رفتار مشابه دارند. SVM به margin اهمیت می‌دهد.

وقتی مدل‌های با inductive bias متفاوت را ensemble کنیم:

امکان complementary errors بیشتر می‌شود.

79. چرا Stacking قدرتمند است؟

فرض کن:

Linear Model

در روابط linear خوب است.

و:

Tree Model

در interactions و nonlinear patterns خوب است.

Meta learner می‌تواند یاد بگیرد:

اگر pattern شبیه X بود → به Tree بیشتر اعتماد کن اگر pattern شبیه Y بود → به Linear Model بیشتر اعتماد کن

این یکی از دلایل قدرت Stacking است.

80. Bias Reduction در Boosting

Boosting معمولاً با:

$$Weak Learners$$

شروع می‌کند.

مثلاً:

Tree depth = 1

یک stump به تنهایی bias بالایی دارد.

اما:

Stump 1 + Stump 2 + Stump 3 + ...

می‌تواند function پیچیده‌ای بسازد.

پس:

$$Bias \downarrow$$

81. Variance Reduction در Bagging

درخت‌های deep:

$$Variance \uparrow$$

دارند.

Bagging:

Tree 1 Tree 2 Tree 3 ... Tree N

و averaging:

$$Variance \downarrow$$

82. آیا Boosting فقط Bias را کم می‌کند؟

نه.

این یک simplification است.

Boosting می‌تواند:

Bias را کم کند

اما با افزایش complexity می‌تواند:

Variance را هم افزایش دهد.

بنابراین:

$$Boosting \neq "Never Overfits"$$

83. آیا Bagging فقط Variance را کم می‌کند؟

هدف اصلی بله.

ولی ensemble می‌تواند bias را نیز به شکل غیرمستقیم تغییر دهد.

بنابراین:

Bias/variance labels ابزار مفهومی‌اند، نه قوانین مطلق.

84. Voting vs Stacking

Voting ترکیب از پیش تعریف شده: Average or Majority Vote Stacking ترکیب: Learned by Meta Model

پس:

$$Voting = Fixed Combination$$

و:

$$Stacking = Learned Combination$$

85. Blending vs Weighted Voting

هر دو می‌توانند weighted combination داشته باشند.

اما تفاوت مهم:

Weighted Voting وزن‌ها مستقیماً برای ترکیب predictionها استفاده می‌شوند. Blending یک validation set برای یادگیری combination استفاده می‌شود.

مثلاً:

Model A = 0.2 Model B = 0.5 Model C = 0.3

این weights می‌توانند از یک meta-model یاد گرفته شوند.

86. Classification و Regression

Ensemble در هر دو قابل استفاده است.

Classification Majority Vote Probability Average Meta Classifier Regression Mean Weighted Mean Meta Regressor

87. Ensemble و Probability Calibration

برای:

$$Soft Voting$$

و:

$$Stacking$$

probability quality مهم است.

فرض کن:

Model A → 0.99 Model B → 0.60 Model C → 0.55

اگر A شدیداً overconfident باشد، average ممکن است تحت تأثیر قرار گیرد.

پس:

$$Calibration matters$$

88. Data Leakage در Ensemble

یکی از خطرناک‌ترین مشکلات:

Training meta-model روی predictionهای in-sample.

غلط:

Train Base Model ↓ Predict same training data ↓ Meta Model

درست:

K-Fold ↓ OOF Predictions ↓ Meta Model

این را در مصاحبه حتماً بگو.

89. Test Set در Ensemble

Test set باید:

فقط برای final evaluation

باشد.

نباید:

Test performance ↓ Tune weights ↓ Retrain ↓ Test again

انجام دهی.

چون test set تبدیل می‌شود به:

$$Validation set$$

و estimate نهایی دیگر unbiased نیست.

90. Ensemble و Cross-Validation

برای انتخاب:

• number of trees • depth • learning rate • weights • meta model

از:

$$Cross-Validation$$

استفاده کن.

اما مراقب باش:

CV داخل pipeline انجام شود.

به خصوص preprocessingهایی مثل:

• imputation • scaling • feature selection • target encoding

نباید قبل از CV روی کل data fit شوند.

🎯 Senior Interview Questions

سؤال 1

Why does Random Forest reduce variance?

جواب:

It averages predictions from many randomized, decorrelated trees. Bootstrap sampling and random feature selection increase diversity and reduce correlation between trees, making averaging effective at reducing variance.

سؤال 2

Why is Boosting sequential?

چون هر learner جدید از وضعیت فعلی ensemble استفاده می‌کند و تلاش می‌کند error یا negative gradient باقی‌مانده را کاهش دهد.

سؤال 3

Bagging vs Boosting؟

Bagging trains models independently and primarily reduces variance, while boosting trains models sequentially to correct previous errors and primarily targets bias reduction.

سؤال 4

Why can Random Forest overfit less than a single deep tree?

چون averaging تعداد زیادی tree و decorrelation بین آنها variance را کاهش می‌دهد.

سؤال 5

Why does Random Feature Selection help?

چون correlation بین trees را کاهش می‌دهد و در نتیجه averaging مؤثرتر می‌شود.

سؤال 6

XGBoost vs Random Forest؟

Random Forest is a bagging-based ensemble of randomized trees, while XGBoost is a sequential gradient boosting framework that adds trees to minimize a regularized objective.

سؤال 7

Stacking leakage را چگونه جلوگیری می‌کنی؟

با استفاده از out-of-fold predictions برای training meta-model، نه in-sample predictions.

سؤال 8

Stacking vs Voting؟

Voting uses a predefined aggregation rule, while stacking learns how to combine base model predictions using a meta-learner.

سؤال 9

آیا افزایش تعداد trees همیشه performance را بهتر می‌کند؟

نه.

در Random Forest معمولاً بعد از نقطه‌ای:

Performance → plateau

می‌شود.

در Boosting افزایش بیش از حد می‌تواند:

Overfitting

ایجاد کند.

سؤال 10

آیا Boosting همیشه بهتر از Bagging است؟

خیر.

به:

• dataset • noise • sample size • feature types • computational constraints • hyperparameters • objective

وابسته است.

اگر در مصاحبه فقط سه نکته از این فصل را بتوانی بگویی:

1️⃣ Bagging

$$Bootstrap + Aggregation \rightarrow Variance Reduction$$

2️⃣ Boosting

$$Sequential Error Correction \rightarrow Bias Reduction$$

3️⃣ Stacking

$$Different Models + OOF Predictions + Meta Learner \rightarrow Learned Combination$$

$$Ensemble Performance \approx Model Quality + Error Diversity$$
