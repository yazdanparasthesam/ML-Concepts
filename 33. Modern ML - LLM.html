1. Embeddings

مفهوم اصلی

Embedding یعنی:

تبدیل یک داده پیچیده (text/image/audio/code) به یک بردار عددی که معنی آن داده را حفظ می‌کند.

مثلاً:

متن:

I love machine learning

تبدیل می‌شود به:

[ 0.123, -0.532, 0.823, ... ]

مثلاً:

dimension = 1536

یعنی یک بردار با 1536 عدد.

چرا Embedding لازم داریم؟

کامپیوتر نمی‌فهمد:

cat

و:

kitten

معنی نزدیک دارند.

ولی embedding می‌تواند:

cat [ 0.21, 0.45, 0.78 ]

و:

kitten [ 0.22, 0.44, 0.75 ]

بسازد.

پس:

Distance کم → معنی نزدیک‌تر

2. Semantic Representation

Embedding فقط کلمه را ذخیره نمی‌کند.

بلکه:

Syntax + Meaning + Context

مثلاً:

کلمات متفاوت هستند.

ولی معنی مشابه است.

Embedding این similarity را capture می‌کند.

6. Vector Similarity

بعد از embedding باید similarity را حساب کنیم.

سه معیار مهم:

6.1 Cosine Similarity

رایج‌ترین.

فرمول:

cos(θ) = A.B / (||A|| ||B||)

مقدار:

-1 تا 1

معمولاً:

1 = identical direction 0 = unrelated -1 = opposite

مثال:

Vector A:

[1,2,3]

Vector B:

[2,4,6]

Cosine:

1

چون جهت یکسان دارند.

6.2 Euclidean Distance

فاصله:

d = √( Σ(xi - yi)² )

کمتر بهتر.

6.3 Dot Product
A.B

در بعضی embedding modelها استفاده می‌شود.

33. KV Cache

یکی از مهم‌ترین تکنیک‌های inference.

در Transformer:

Attention:

Q K V

در generation:

هر token جدید نیاز دارد گذشته را دوباره حساب کند.

KV Cache:

Key و Value قبلی را ذخیره می‌کند.

بدون cache:

Generate token 1 Compute all Generate token 2 Compute token1 again

با cache:

Store previous K,V Only compute new token

نتیجه:

Latency بسیار کمتر.

38. Retrieval Evaluation

برای RAG باید Retrieval را جدا بررسی کنیم.
