🧪 25. Error Analysis

یکی از مهم‌ترین مهارت‌های Senior ML Engineer. به جای اینکه فقط بگویی: F1 = 0.91 می‌پرسی: Where does the model fail? مثلاً:

  • False Positives
  • False Negatives
  • Rare Cases
  • Specific User Groups
  • Specific Time Periods
  • Specific Products

این مرحله خیلی وقت‌ها از Hyperparameter Tuning مهم‌تر است.
