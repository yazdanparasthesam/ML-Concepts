1. Vanishing Gradient

یکی از کلاسیک‌ترین مشکلات Deep Neural Networks است.

فرض کنید شبکه‌ای با لایه‌های زیاد داریم:

x ↓ Layer 1 ↓ Layer 2 ↓ Layer 3 ↓ ... ↓ Layer 50 ↓ Output

در Backpropagation گرادیان با استفاده از Chain Rule از خروجی به سمت ورودی حرکت می‌کند.

اگر:

∂L / ∂w

در هر layer کمی کوچک‌تر شود، بعد از عبور از ده‌ها layer ممکن است تقریباً صفر شود.

Chain Rule

به شکل ساده:

∂L / ∂x = (∂L / ∂z3) * (∂z3 / ∂z2) * (∂z2 / ∂z1) * (∂z1 / ∂x)

اگر هر کدام مثلاً:

0.1

باشد:

0.110 = 10-10

پس gradient تقریباً ناپدید می‌شود.

نتیجه

لایه‌های ابتدایی:

gradient ≈ 0

و در نتیجه:

weights ≈ don't learn
Sigmoid و Vanishing Gradient

Sigmoid:

σ(x) = 1 / (1 + e-x)

مشتق آن:

σ'(x) = σ(x)(1 - σ(x))

حداکثر مشتق:

0.25

است.

بنابراین در شبکه عمیق، ضرب تعداد زیادی مقدار کوچک باعث vanishing gradient می‌شود.

4. Gradient Clipping

یکی از راه‌های مقابله با exploding gradient.

مثلاً:

||g|| > threshold

اگر gradient بیش از حد بزرگ باشد، آن را scale می‌کنیم.

برای norm clipping:

g' = g * (c / ||g||)

وقتی:

||g|| > c

باشد.

مثلاً:

max_grad_norm = 1.0

در training مدل‌های sequence و Transformer بسیار رایج است.

6. Batch Normalization

BatchNorm activationهای داخل شبکه را normalize می‌کند.

برای یک feature:

μB = (1/m) Σi xi

و:

σB2 = (1/m) Σi (xi - μB)2

سپس:

x̂ = (x - μB) / √(σB2 + ε)

و در نهایت:

y = γx̂ + β

دو پارامتر:

γ: scale
β: shift

قابل یادگیری هستند.

7. BatchNorm دقیقاً چه چیزی را normalize می‌کند؟

این موضوع خیلی مهم است.

فرض کنید:

Batch × Features

داریم.

BatchNorm برای هر feature، statistics را روی batch محاسبه می‌کند.

یعنی تقریباً:

Feature 1: samples → mean/std Feature 2: samples → mean/std

9. مشکل BatchNorm

BatchNorm به batch statistics وابسته است.

اگر:

batch size = 256

باشد معمولاً statistics پایدارتر است.

ولی:

batch size = 2

ممکن است statistics noisy شوند.

به همین دلیل در برخی معماری‌ها و مخصوصاً مدل‌های sequence / Transformer، LayerNorm ترجیح داده می‌شود.

10. Layer Normalization

LayerNorm به جای اینکه statistics را روی batch بگیرد، داخل representation هر نمونه normalize می‌کند.

به‌صورت مفهومی:

Sample 1 [f1 f2 f3 f4] ↓ normalize

و مستقل از نمونه‌های دیگر است.

13. Pre-Norm vs Post-Norm

این موضوع مخصوصاً در Transformerها مهم است.

فرض کنید:

x ↓ Attention ↓ Residual ↓ Normalization

این تقریباً Post-Norm است.

در Post-Norm:

x' = LN(x + F(x))

14. Pre-Norm

در Pre-Norm:

x ↓ LayerNorm ↓ Attention ↓ Residual

فرمول:

x' = x + F(LN(x))

15. تفاوت Pre-Norm و Post-Norm

Post-Norm
LN(x + F(x))
Pre-Norm
x + F(LN(x))

16. چرا Pre-Norm مهم است؟

در Transformerهای بسیار عمیق، Pre-Norm معمولاً training stability و gradient flow بهتری فراهم می‌کند.

به‌خصوص:

Very Deep Transformer

می‌تواند با Pre-Norm راحت‌تر train شود.

اما trade-offهایی در optimization dynamics و representation quality وجود دارد؛ بنابراین نمی‌توان گفت Pre-Norm در همه شرایط مطلقاً بهتر است.

17. Residual Learning

ایده بسیار مهم:

به جای اینکه شبکه مستقیماً:

H(x)

را یاد بگیرد، یاد می‌گیرد:

F(x) = H(x) - x

سپس:

H(x) = F(x) + x

18. چرا Residual Connection مفید است؟

فرض کنید شبکه می‌خواهد identity mapping یاد بگیرد:

H(x) = x

در معماری معمولی باید چند layer یاد بگیرند:

H(x) = x

اما در residual:

F(x) = 0

کافی است.

19. Residual و Gradient Flow

فرض:

y = x + F(x)

پس:

∂y / ∂x = 1 + ∂F / ∂x

وجود آن:

1

باعث می‌شود مسیر مستقیم برای عبور gradient وجود داشته باشد.

این یکی از دلایل مهم موفقیت شبکه‌های عمیق است.

20. Attention Mechanism

Attention به شبکه اجازه می‌دهد:

هنگام تولید representation یک token، به بخش‌های مختلف input با وزن‌های متفاوت توجه کند.

مثلاً:

The animal didn't cross the road because it was tired.

برای درک it باید رابطه آن با animal را بفهمیم.

Attention می‌تواند چنین dependencyهایی را مدل کند.

21. Query, Key, Value

Attention سه مفهوم دارد:

Query Key Value

می‌توانیم خیلی ساده تصور کنیم:

Query

من دنبال چه چیزی هستم؟

Key

هر token چه نوع اطلاعاتی دارد؟

Value

اگر به آن token توجه کنم چه اطلاعاتی دریافت می‌کنم؟

22. Scaled Dot-Product Attention

فرمول اصلی:

Attention(Q, K, V) = softmax( QKT / √dk )V

سه مرحله:

QKᵀ ↓ Similarity Scores ↓ Scaling ↓ Softmax ↓ Weighted Sum of V

23. چرا تقسیم بر √dk؟

اگر dimension زیاد شود، dot productها می‌توانند magnitude بزرگی داشته باشند.

در نتیجه Softmax ممکن است بیش از حد sharp شود.

تقسیم بر:

√dk

variance را کنترل می‌کند.

24. Self-Attention

در Self-Attention:

Q ← same sequence K ← same sequence V ← same sequence

مثلاً:

I love machine learning

هر token می‌تواند به tokenهای دیگر توجه کند.

25. Self-Attention vs Cross-Attention

Self-Attention

Q/K/V از یک sequence می‌آیند.

Cross-Attention

Query از یک sequence و Key/Value از sequence دیگری می‌آیند.

مثلاً در encoder-decoder:

Decoder Query ↓ Encoder Key/Value

26. Multi-Head Attention

به جای یک attention:

Attention

داریم:

Head 1 Head 2 Head 3 ... Head h

هر head می‌تواند representation متفاوتی از روابط را یاد بگیرد.

27. معماری Multi-Head Attention

به شکل مفهومی:

Input | +----> Head 1 | +----> Head 2 | +----> Head 3 | +----> ... | +----> Head h | Concatenate | Linear Layer

29. Positional Encoding

یک مشکل اساسی:

Self-Attention ذاتاً permutation-equivariant است.

یعنی اگر ترتیب tokenها را عوض کنیم، بدون اطلاعات positional مناسب، مدل به‌صورت ذاتی نمی‌فهمد که ترتیب تغییر کرده است.

مثلاً:

Dog bites man

با:

Man bites dog

متفاوت است.

پس باید اطلاعات position وارد representation شود.

30. Sinusoidal Positional Encoding

در Transformer اولیه از توابع sin/cos استفاده شد:

PE(pos, 2i) = sin( pos / 100002i/d )

و:

PE(pos, 2i+1) = cos( pos / 100002i/d )

37. Transfer Learning

ایده:

39. Fine-Tuning

در Fine-Tuning:

مدل pretrained را روی task جدید با داده جدید ادامه می‌دهیم.

مثلاً:

Pretrained BERT ↓ Fraud Text Dataset ↓ Fine-Tuning ↓ Fraud Classifier

40. Full Fine-Tuning

تمام پارامترهای مدل قابل آموزش هستند.

مثلاً:

Model: 7B parameters Trainable: 7B
مزیت

Maximum flexibility.

مشکل

Memory بسیار زیاد.

چون علاوه بر weights باید برای optimizer و gradients هم memory داشته باشیم.

41. Freezing Layers

در freezing:

بعضی پارامترها را ثابت می‌کنیم.

مثلاً:

Layer 1 ❄️ frozen Layer 2 ❄️ frozen Layer 3 ❄️ frozen Layer 4 🔥 trainable Layer 5 🔥 trainable

در PyTorch:

Python
for param in model.parameters(): param.requires_grad = False

و سپس فقط بخش مورد نظر را train می‌کنیم.

42. چرا Freeze کنیم؟

برای:

کاهش training cost
کاهش memory
جلوگیری از overfitting
سرعت بیشتر

مفید است.

اما اگر task جدید خیلی متفاوت باشد، freezing بیش از حد می‌تواند ظرفیت adaptation را محدود کند.

43. Fine-Tuning vs Feature Extraction

Feature Extraction

مدل pretrained را تقریباً ثابت نگه می‌داریم و فقط:

47. LoRA

Low-Rank Adaptation

ایده بسیار مهم:

به جای اینکه matrix اصلی را مستقیماً update کنیم:

W

یک update کم‌رتبه اضافه می‌کنیم:

W' = W + ΔW

و:

ΔW = BA

که:

B ∈ Rd×r

و:

A ∈ Rr×k

و:

r << min(d, k)

48. چرا Low-Rank؟

فرض کنید:

W ∈ R4096×4096

پارامترهای کامل:

40962

اما اگر:

r = 8

باشد:

A ∈ R8×4096

و:

B ∈ R4096×8

در نتیجه تعداد پارامترهای trainable بسیار کمتر می‌شود.

49. نکته مهم LoRA

در LoRA:

Base model weights → Frozen LoRA matrices → Trainable

در inference می‌توانیم adapter را:

merge

کنیم.

یعنی:

W' = W + BA

و در برخی deploymentها می‌توان مدل merged را مانند مدل عادی اجرا کرد.

50. LoRA معمولاً کجا اعمال می‌شود؟

در Transformer معمولاً روی projectionهای attention:

Wq Wk Wv Wo

و گاهی روی لایه‌های MLP.

اما اینکه دقیقاً کدام moduleها انتخاب شوند یک hyperparameter / engineering decision است.

51. LoRA Hyperparameters

چند پارامتر مهم:

r = 4 8 16 32 64

rank بیشتر:

67. انواع Distillation

Response Distillation

Student خروجی Teacher را تقلید می‌کند.

Feature Distillation

representationهای intermediate را نیز تقلید می‌کند.

Logit Distillation

Student logits Teacher را تقلید می‌کند.

Attention Distillation

attention patterns نیز می‌توانند هدف distillation باشند.

69. نکته بسیار مهم: Distillation ≠ Fine-Tuning

این دو را نباید قاطی کنیم.

Fine-Tuning

مدل را با داده task جدید تطبیق می‌دهیم.

Distillation

مدل Student را آموزش می‌دهیم تا رفتار/knowledge یک Teacher را تقلید کند.

می‌توانیم حتی هر دو را ترکیب کنیم:

Pretrained Student ↓ Distillation Fine-Tuning ↓ Small Specialized Model

75. نکات بسیار مهم مصاحبه Senior

❓ چرا Residual Connection کمک می‌کند؟

به دلیل وجود مسیر identity که gradient را بهتر منتقل می‌کند:

∂(x + F(x)) / ∂x = 1 + ∂F(x) / ∂x
❓ چرا Transformer به Positional Encoding نیاز دارد؟

چون attention به‌تنهایی ترتیب sequence را به شکل موردنیاز مدل نمی‌کند و باید اطلاعات موقعیت را به معماری اضافه کنیم.

❓ چرا LayerNorm در Transformer رایج است؟

چون به batch statistics وابسته نیست و برای sequence modeling مناسب‌تر است.

❓ Pre-Norm چیست؟
x + F(LN(x))

Normalization قبل از sublayer قرار می‌گیرد.

❓ LoRA چه چیزی را train می‌کند؟

به‌جای update کردن W، یک low-rank update:

ΔW = BA

را train می‌کند.

❓ QLoRA چیست؟

ترکیب:

Quantized Frozen Base Model + Trainable LoRA Adapters
❓ LoRA چرا memory را کاهش می‌دهد؟

چون تعداد پارامترهای trainable، gradientها و optimizer states مربوط به پارامترهای قابل‌آموزش به‌شدت کاهش پیدا می‌کنند.

❓ Knowledge Distillation چیست؟

آموزش Student برای تقلید از behavior یا knowledge یک Teacher بزرگ‌تر.

76. مهم‌ترین Mental Model

اگر بخواهم کل فصل را در چند جمله خلاصه کنم:

Vanishing/Exploding Gradient مشکلات optimization در شبکه‌های عمیق هستند.
Residual Connections و Normalization به stable training شبکه‌های عمیق کمک می‌کنند.
Attention اجازه می‌دهد مدل وابستگی‌های مختلف بین عناصر sequence را به‌صورت داده‌محور وزن‌دهی کند.
Self-Attention روابط داخل همان sequence را مدل می‌کند.
Multi-Head Attention چند projection مستقل از attention را ترکیب می‌کند.
Positional Encoding / Representation اطلاعات ترتیب را وارد Transformer می‌کند.
Encoder/Decoder الگوهای مختلفی برای تبدیل input به representation یا output هستند.
Transfer Learning دانش pretrained را به task جدید منتقل می‌کند.
Fine-Tuning پارامترهای pretrained model را برای task/domain جدید تطبیق می‌دهد.
PEFT این adaptation را با تعداد کمی پارامتر trainable انجام می‌دهد.
LoRA adaptation را به یک low-rank update تبدیل می‌کند.
QLoRA همین ایده را روی یک base model کوانتایز‌شده برای کاهش بیشتر memory اجرا می‌کند.
Knowledge Distillation دانش/رفتار مدل بزرگ را به مدل کوچک منتقل می‌کند.

و مهم‌ترین نگاه Senior:

Quality ↑ │ Full FT ─────┤───── Maximum flexibility │ LoRA ───────┤───── Efficient adaptation │ QLoRA ───────┤───── Extreme memory efficiency │ Distillation ──┤───── Smaller / faster model │ └────────────────────→ Cost / Complexity

Senior ML Engineer کسی نیست که فقط همه این اصطلاحات را تعریف کند؛ باید بتواند بین Full Fine-Tuning، LoRA، QLoRA، Freezing و Distillation بر اساس data size + GPU/VRAM + latency + quality target + deployment cost + domain shift تصمیم مهندسی بگیرد.
