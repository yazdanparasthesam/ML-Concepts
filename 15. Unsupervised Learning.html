🔬 15. Unsupervised Learning

حتماً. این فصل را باید کمی عمیق‌تر از «تعریف الگوریتم» ببینیم، چون در سطح Senior ML مهم است بدانی:

  • الگوریتم دقیقاً چه فرضی درباره داده دارد؟
  • objective آن چیست؟
  • چه نوع cluster / anomaly را می‌تواند پیدا کند؟
  • با noise و outlier چه می‌کند؟
  • چه زمانی scale کردن لازم است؟
  • چطور hyperparameterها را انتخاب می‌کنی؟
  • چطور ارزیابی می‌کنی وقتی label نداری؟
  • و مهم‌تر از همه: چه زمانی اصلاً نباید از clustering استفاده کنی؟

1. Unsupervised Learning چیست؟

در supervised learning داریم:

$$(X, Y)$$

و هدف یادگیری:

$$f : X \to Y$$

است.

اما در unsupervised learning معمولاً:

$$X$$

داریم و Y نداریم.

هدف این است که ساختار پنهان داده را پیدا کنیم:

$$X \to \text{Structure}$$

مثلاً:

Customers │ ▼ Unsupervised Learning │ ▼ Customer Segments

یا:

Transactions │ ▼ Anomaly Detection │ ▼ Suspicious Transactions

3. Clustering چیست؟

هدف clustering این است که داده‌ها را به گروه‌هایی تقسیم کنیم که:

  • داخل هر گروه مشابه‌تر باشند
  • بین گروه‌ها متفاوت‌تر باشند

مثلاً:

● ● ● ● ● ● ▲ ▲ ▲ ▲ ▲ ▲ ▲ ■ ■ ■ ■ ■

ممکن است الگوریتم سه cluster پیدا کند:

  • Cluster 1 → ●
  • Cluster 2 → ▲
  • Cluster 3 → ■
⚠️ نکته بسیار مهم

clustering همیشه به معنی کشف «کلاس واقعی» نیست.

Cluster چیزی است که الگوریتم بر اساس objective و assumptions خودش تعریف می‌کند.

4. Clustering با Classification فرق دارد

Classification
$$X \to \text{known labels}$$
مثلاً: transaction → fraud / legitimate
Clustering
$$X \to \text{unknown groups}$$
مثلاً: transaction → cluster 1 / 2 / 3

7. K-Means

یکی از مهم‌ترین الگوریتم‌های clustering.

فرض کن:

$$X = \{x_1, x_2, \dots, x_n\}$$

و می‌خواهیم:

$$K$$

cluster داشته باشیم.

K-Means سعی می‌کند هر point را به نزدیک‌ترین centroid اختصاص دهد.

7.1 Centroid چیست؟

برای cluster k:

$$\mu_k = \frac{1}{|C_k|} \sum_{x_i \in C_k} x_i$$

یعنی میانگین نقاط cluster.

مثلاً:

Points: (1,1) (2,2) (3,3)
Centroid: (2,2)

8. Objective تابع K-Means

K-Means معمولاً این objective را minimize می‌کند:

$$\sum_{k=1}^K \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$

یعنی:

مجموع squared distance نقاط تا centroid خودشان را کمینه کن.

این را می‌توان:

WCSS

یا:

Within-Cluster Sum of Squares

نیز در نظر گرفت.

9. الگوریتم K-Means

K-Means به صورت iterative کار می‌کند.

Step 1

K centroid اولیه انتخاب کن.

μ₁ μ₂ μ₃
Step 2

هر point را به نزدیک‌ترین centroid اختصاص بده.

x → nearest centroid
Step 3

Centroidها را دوباره محاسبه کن.

Step 4

این کار را تکرار کن:

Assign ↓ Update ↓ Assign ↓ Update

تا convergence.

10. چرا اسمش K-Means است؟

  • K = تعداد clusterها
  • Means = centroid با میانگین نقاط ساخته می‌شود

11. K-Means یک الگوریتم Global Optimization ساده نیست

⚠️ نکته Senior

Objective آن non-convex نسبت به assignment و centroids به صورت مشترک است و الگوریتم Lloyd معمولاً به:

local optimum

می‌رسد.

بنابراین initialization مهم است.

12. K-Means++

برای initialization بهتر از:

Random Initialization

استفاده می‌شود. K-Means++ centroidهای اولیه را طوری انتخاب می‌کند که معمولاً از هم فاصله بیشتری داشته باشند. در نتیجه: convergence بهتر، احتمال solution خوب بیشتر، حساسیت کمتر به initialization.

K-Means distance-based است. مثلاً: age: 20-60, income: 10,000-10,000,000. اگر scaling نکنیم: income تقریباً تمام distance را کنترل می‌کند.

K-Means برای clusterهایی که تقریباً: spherical, convex, مشابه از نظر spread, بر اساس Euclidean distance قابل تفکیک هستند مناسب‌تر است.

18. K-Medoids

در K-Means: centroid = mean است. اما در K-Medoids: نماینده cluster یکی از خود نقاط داده است.

  • K-Means: centroid = artificial point
  • K-Medoids: medoid = actual observation

19. مزیت K-Medoids

چون median-like representative دارد، معمولاً: نسبت به outlierها robustتر از K-Means است.

24. Silhouette Score

یکی از مهم‌ترین metricهای clustering. برای point i:

$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$

که: a(i) میانگین فاصله point از cluster خودش، b(i) کمترین میانگین فاصله از یک cluster دیگر. مقدار: -1 ≤ s(i) ≤ 1

25. تفسیر Silhouette

  • نزدیک +1 → point داخل cluster خودش خوب قرار گرفته.
  • نزدیک 0 → point بین دو cluster است.
  • منفی → ممکن است به cluster دیگری تعلق بیشتری داشته باشد.

26. نکته مهم درباره Silhouette

Silhouette هم distance-based است. پس اگر distance metric نامناسب باشد، metric هم می‌تواند misleading شود.

27. Hierarchical Clustering

Hierarchical clustering به جای اینکه فقط K clusters بدهد، یک hierarchy می‌سازد. نمایش رایج: Dendrogram

28. Agglomerative Clustering

روش bottom-up:

Each point = cluster │ ▼ Merge closest clusters │ ▼ Merge │ ▼ Merge │ ▼ One big cluster

29. مثال

فرض کن: A B C D E

ابتدا: {A} {B} {C} {D} {E}

بعد: {A,B} {C} {D,E}

بعد: {A,B,C} {D,E}

و در نهایت: {A,B,C,D,E}

30. Dendrogram

┌───────────────┐ │ │ ┌───┴───┐ ┌───┴───┐ A B C D

با cut کردن dendrogram در ارتفاع خاص، تعداد clusterها تعیین می‌شود.

31. Linkage

یکی از مهم‌ترین hyperparameterهای hierarchical clustering: Linkage

فاصله بین دو cluster را چطور تعریف کنیم؟

32. Single Linkage

فاصله دو cluster: نزدیک‌ترین دو point

$$d(A, B) = \min_{x \in A, y \in B} d(x, y)$$

33. مشکل Single Linkage

ممکن است: chaining effect ایجاد کند. حتی اگر ساختار دو گروه باشد، نقاط intermediate باعث اتصال آنها می‌شوند.

34. Complete Linkage

فاصله: دورترین دو point

$$d(A, B) = \max_{x \in A, y \in B} d(x, y)$$

معمولاً clusterهای compactتری می‌دهد.

35. Average Linkage

میانگین فاصله تمام pairها:

$$d(A, B) = \frac{1}{|A||B|} \sum_{x \in A} \sum_{y \in B} d(x, y)$$

36. Ward Linkage

Ward سعی می‌کند افزایش Within Cluster Variance را هنگام merge کمینه کند. برای clusterهای تقریباً spherical بسیار مفید است.

38. DBSCAN

DBSCAN: Density-Based Spatial Clustering of Applications with Noise

cluster = region with sufficiently high density

این تفاوت بسیار مهمی با K-Means دارد.

39. دو hyperparameter اصلی DBSCAN

  • eps شعاع neighborhood: ε
  • min_samples حداقل تعداد نقاط برای dense بودن neighborhood.

40. Core Point

اگر در شعاع ε حداقل minPts نقطه داشته باشیم، point یک Core Point است.

41. Border Point

نقطه‌ای که خودش density کافی ندارد ولی در neighborhood یک core point قرار دارد: Border Point.

42. Noise

نقطه‌ای که core نیست و border هم نیست به عنوان Noise علامت می‌خورد.

✅ ویژگی بسیار مهم DBSCAN

K-Means مجبور است تقریباً هر point را به clusterی نسبت دهد؛ DBSCAN می‌تواند Noise تولید کند.

43. DBSCAN مزیت مهم

می‌تواند clusterهای non-spherical پیدا کند.

44. DBSCAN و Outlier Detection

Noiseهای DBSCAN می‌توانند به عنوان candidate anomaly استفاده شوند. اما DBSCAN ذاتاً anomaly detector کامل نیست چون classification به عنوان noise شدیداً به eps, minPts وابسته است.

45. مشکل بزرگ DBSCAN

DBSCAN با varying density مشکل دارد. یک eps ثابت ممکن است برای دو cluster با density متفاوت مناسب نباشد.

46. Curse of Dimensionality برای DBSCAN

DBSCAN distance-based است. در high dimensions distanceها کمتر meaningful می‌شوند. در نتیجه انتخاب eps بسیار سخت می‌شود.

Scaling │ ▼ Dimensionality Reduction │ ▼ DBSCAN
⚠️ ولی

dimensionality reduction خودش می‌تواند structure را تغییر دهد، بنابراین باید validation شود.

47. HDBSCAN

HDBSCAN: Hierarchical Density-Based Spatial Clustering of Applications with Noise

در واقع ایده DBSCAN را توسعه می‌دهد تا densityهای مختلف را بهتر handle کند.

48. تفاوت DBSCAN و HDBSCAN

  • DBSCAN: one eps
  • HDBSCAN: hierarchy of density levels

49. HDBSCAN چه کار می‌کند؟

Data │ ▼ Density hierarchy │ ▼ Cluster tree │ ▼ Select stable clusters │ ▼ Noise

50. Cluster Stability در HDBSCAN

HDBSCAN فقط دنبال cluster نیست. به نوعی clusterهایی را ترجیح می‌دهد که در طی rangeای از density پایدار بمانند. این مفهوم Cluster Stability یکی از نکات کلیدی HDBSCAN است.

51. مزیت HDBSCAN

  • varying density بهتر
  • hierarchical structure
  • noise handling
  • نیاز کمتر به انتخاب یک global eps

52. HDBSCAN و Probability

در بسیاری از implementationها می‌توان برای membership یک point نوعی confidence/probability داشت. پس به جای point → cluster 2 می‌توان دید: cluster 2 membership strength = 0.91

54. Gaussian Mixture Model

حالا می‌رسیم به probabilistic clustering

K-Means می‌گوید: point → cluster 1

اما GMM می‌تواند بگوید:

P(cluster 1 | x) = 0.8
P(cluster 2 | x) = 0.2

یعنی Soft Clustering

55. GMM چیست؟

فرض می‌کنیم داده از mixtureای از Gaussianها آمده است:

$$p(x) = \sum_{k=1}^K \pi_k \mathcal{N}(x \mid \mu_k, \Sigma_k)$$

که: πₖ = mixing coefficient, μₖ = mean, Σₖ = covariance

56. Mixing Coefficient

باید داشته باشیم: πₖ ≥ 0 و ∑ πₖ = 1

مثلاً: Cluster 1 → π=0.5, Cluster 2 → π=0.3, Cluster 3 → π=0.2

57. Soft Assignment

برای point x: P(z = k | x) محاسبه می‌شود.

Customer X
Cluster A → 0.05
Cluster B → 0.90
Cluster C → 0.05

58. GMM با K-Means چه ارتباطی دارد؟

K-Means را می‌توان یک حالت محدودشده از مدل mixture در نظر گرفت.

K-Means
→ hard assignment
→ spherical clusters
→ similar variance
GMM
→ soft assignment
→ probabilistic
→ covariance-aware

59. Covariance در GMM

این یکی از مزیت‌های مهم GMM است. Gaussian می‌تواند کشیده باشد. یعنی cluster می‌تواند elliptical باشد. K-Means بیشتر به فاصله تا centroid وابسته است.

60. انواع Covariance در GMM

  • Full: هر Gaussian covariance matrix خودش را دارد Σₖ – انعطاف‌پذیرترین حالت.
  • Diagonal: فقط varianceهای featureها Σₖ = diag(σ₁², …, σ_d²)
  • Spherical: یک variance Σₖ = σₖ² I
  • Tied: همه clusterها covariance مشترک دارند.

61. GMM با چه الگوریتمی آموزش می‌بیند؟

معمولاً: Expectation-Maximization یا EM

62. EM در GMM

E-Step

Probability membership را محاسبه می‌کنیم: γᵢₖ = P(zᵢ = k | xᵢ)

M-Step

پارامترهای Gaussianها را با توجه به این membershipها update می‌کنیم.

E-Step │ ▼ M-Step │ ▼ E-Step │ ▼ M-Step

تا convergence.

63. GMM و Local Optimum

⚠️ EM نیز معمولاً تضمین نمی‌کند که به global optimum برسد.

بنابراین initialization مهم است. ممکن است چند initialization را امتحان کنیم.

64. انتخاب K در GMM

برای GMM فقط Elbow کافی نیست. معمولاً AIC = 2k - 2 log L و BIC = k log n - 2 log L را بررسی می‌کنیم. BIC معمولاً penalty بیشتری برای complexity دارد.

65. GMM و Anomaly Detection

GMM می‌تواند p(x) را تخمین بزند. اگر p(x) ≪ باشد، point می‌تواند anomaly باشد. یا از -log p(x) به عنوان anomaly score استفاده کنیم.

66. Density Estimation

حالا مفهوم مهم: Density Estimation

هدف: تخمین distribution داده

یعنی به جای فقط cluster assignment، می‌خواهیم p(x) را تخمین بزنیم.

67. چرا Density مهم است؟

اگر distribution را بدانیم، می‌توانیم: احتمال observation, anomaly score, sampling, uncertainty, generative modeling را بررسی کنیم.

68. Parametric Density Estimation

مثلاً فرض کنیم X ∼ N(μ, σ²) و پارامترها را تخمین بزنیم: μ, σ. این یک مدل Parametric است.

69. GMM یک Density Estimator است

چون p(x) = ∑ πₖ N(x|μₖ, Σₖ) را مدل می‌کند. پس GMM هم clustering است و هم density estimation.

70. Non-Parametric Density Estimation

مثلاً Kernel Density Estimation یا KDE

$$\hat{f}(x) = \frac{1}{n h} \sum_{i=1}^n K\left(\frac{x - x_i}{h}\right)$$

71. Bandwidth در KDE

یکی از مهم‌ترین hyperparameterها: h

  • اگر h کوچک باشد: density خیلی noisy و spiky می‌شود.
  • اگر بزرگ باشد: over-smoothing رخ می‌دهد.

72. Density Estimation و Curse of Dimensionality

⚠️ KDE در dimensions بالا شدیداً مشکل پیدا می‌کند.

به همین دلیل: Density estimation gets hard in high dimensions

73. Anomaly Detection

هدف: observationهای unusual را پیدا کنیم.
Normal transactions ████████████████████████ X ↑ anomaly

74. Anomaly vs Outlier

Outlier

مشاهده‌ای که نسبت به بقیه unusual است.

Anomaly

مشاهده‌ای که از perspective مسئله: suspicious / abnormal است.

⚠️ نکته

ممکن است یک point statistically rare باشد ولی business anomaly نباشد.

75. سه نوع Anomaly

Point Anomaly

یک observation به تنهایی abnormal است. مثال: transaction = $1,000,000

Contextual Anomaly

در یک context abnormal است. مثال: $500 transaction ممکن است برای یک مشتری عادی باشد، ولی ساعت 4 صبح در یک الگوی خاص غیرعادی شود.

Collective Anomaly

هر point به تنهایی عادی است ولی sequence/group غیرعادی است. مثال: 10,000 requests در 10 ثانیه

76. Isolation Forest

یکی از مهم‌ترین anomaly detection algorithms. ایده بسیار جالب:

Anomalies راحت‌تر از normal points isolate می‌شوند.

77. Isolation Tree

درخت‌هایی با splitهای تصادفی ساخته می‌شود.

X < 50? / \ Yes No | X < 70?

اگر یک point خیلی unusual باشد: با چند split به تنهایی جدا می‌شود.

78. Path Length

  • Anomaly: shorter path
  • Normal: longer path

79. چرا anomaly راحت‌تر isolate می‌شود؟

● ● ● ● ● ● ● ● X

point X فضای خالی زیادی اطرافش دارد. یک random split احتمالاً سریع آن را جدا می‌کند.

80. Isolation Forest

به جای یک tree:

Tree 1 Tree 2 Tree 3 ... Tree N

داریم. بعد path lengthها aggregate می‌شوند. این همان Forest است.

81. Isolation Forest مزیت مهم

  • نیاز به distance matrix ندارد
  • نسبتاً scalable است
  • در high-dimensional settings کاربردی‌تر است
  • distribution خاصی فرض نمی‌کند

82. محدودیت Isolation Forest

⚠️ Random splitting همیشه بهترین representation برای anomaly نیست.

اگر anomaly فقط contextual باشد و feature context را مدل نکرده باشی، ممکن است detection ضعیف شود.

83. Contamination

در Isolation Forest معمولاً یک مفهوم مهم داریم: contamination یعنی تقریباً انتظار داریم چه نسبتی از داده anomaly باشد. مثال: contamination = 0.01 یعنی حدود 1%

84. آیا contamination واقعاً ground truth است؟

نه.

اگر واقعاً anomaly rate را نمی‌دانی، انتخاب آن یک hyperparameter/domain assumption است. در production باید threshold را با business constraints و validation تعیین کنی.

85. One-Class SVM

One-Class SVM با SVM معمولی متفاوت است. SVM classification: Class A vs Class B

اما One-Class SVM:

Normal data │ ▼ learn boundary │ ▼ anything outside → anomaly

86. ایده One-Class SVM

می‌خواهیم یک region پیدا کنیم که بیشتر داده‌های normal را شامل شود. نقاط خارج از این region: outlier / anomaly

87. Kernel در One-Class SVM

One-Class SVM می‌تواند از kernel استفاده کند. مثلاً RBF:

$$K(x, x') = e^{-\gamma \|x - x'\|^2}$$

بنابراین می‌تواند boundary غیرخطی ایجاد کند.

88. پارامترهای مهم One-Class SVM

nu (ν)

تقریباً کنترل می‌کند: upper bound روی fraction of training errors و lower bound روی fraction of support vectors. در عمل به عنوان کنترل حساسیت به outlierها هم دیده می‌شود.

gamma (γ)

در RBF: γ کنترل می‌کند kernel چقدر local باشد. gamma بالا: boundary پیچیده‌تر و localتر. gamma پایین: boundary smoothتر.

89. One-Class SVM و Scaling

⚠️ خیلی مهم

One-Class SVM به scale بسیار حساس است.

StandardScaler │ ▼ One-Class SVM

90. One-Class SVM مشکل scalability دارد

One-Class SVM با kernel برای datasetهای بسیار بزرگ می‌تواند expensive باشد. بنابراین مثلاً 10 million samples ممکن است Isolation Forest گزینه عملی‌تری باشد.

  • HDBSCAN: stable clusters + noise + membership strength

94. ارزیابی Clustering بدون Label

این یکی از سخت‌ترین بخش‌های unsupervised learning است. چون Y نداری. پس نمی‌توانی مستقیماً accuracy یا F1 حساب کنی.

95. Internal Validation

  • Silhouette Score [-1, 1]
  • Davies-Bouldin Index کمتر بهتر: DB ↓
  • Calinski-Harabasz معمولاً: CH ↑ بهتر است.

96. اما این Metricها کافی نیستند

⚠️ مثال:

اگر business goal customer segmentation باشد، بهترین silhouette الزاماً بهترین segmentation نیست. باید بررسی کنی: segment size, stability, interpretability, business actionability, revenue, churn, conversion

97. Cluster Stability

اگر داده را کمی تغییر دهیم، آیا clusterها باقی می‌مانند؟

مثلاً: Bootstrap 1 → A B C, Bootstrap 2 → A B C, Bootstrap 3 → A B C. اگر cluster structure دائماً عوض شود: احتمالاً clustering پایدار نیست.

98. External Validation

اگر بعداً label یا ground truth داشته باشی، می‌توانی از: Adjusted Rand Index, Normalized Mutual Information, purity, Fowlkes-Mallows استفاده کنی. اما باید توجه کنی که cluster labelها arbitrary هستند.

⚠️

Run 1: Cluster 0 = customers A, Cluster 1 = customers B. Run 2: Cluster 0 = customers B, Cluster 1 = customers A. این دو از نظر clustering می‌توانند کاملاً یکسان باشند.

99. Label Switching

⚠️ این مسئله در clustering و GMM بسیار مهم است.

شماره cluster معنی ذاتی ندارد. Cluster 1 ذاتاً معنای خاصی ندارد. ممکن است در run دیگر همان گروه Cluster 3 باشد.

تقریباً تمام الگوریتم‌های distance-based نسبت به scale حساس‌اند: K-Means, DBSCAN, HDBSCAN, Hierarchical, KNN-like methods, One-Class SVM

Imputation │ ▼ Scaling │ ▼ Algorithm

101. اما Tree-based Anomaly Methods

Isolation Forest به اندازه روش‌های distance-based حساس نیست.

این یک نکته مهم عملی است.

102. Categorical Data

K-Means با categorical feature خام مناسب نیست. مثال: country = Iran را نمی‌توان به شکل naive: Iran = 1, Turkey = 2, Germany = 3 داد و Euclidean distance گرفت. چون Germany - Turkey معنی عددی ندارد. باید representation و distance مناسب طراحی شود.

103. High-Dimensional Clustering

در high-dimensional data: d ≫ 1 distanceها ممکن است مشکل‌دار شوند.

Feature Selection │ ▼ Dimensionality Reduction │ ▼ Clustering

مثلاً: 1000 features → PCA → 50 → HDBSCAN

⚠️ اما:

این pipeline باید با objective واقعی ارزیابی شود.

104. آیا PCA همیشه قبل از Clustering خوب است؟

خیر.

ممکن است PCA variance بالا را نگه دارد ولی cluster signal را حذف کند. بنابراین: Raw → KMeans, Raw → HDBSCAN, PCA → KMeans, UMAP → HDBSCAN را می‌توان به عنوان candidate pipelines بررسی کرد.

105. Leakage در Unsupervised Learning

⚠️ فرض کن می‌خواهی clustering را برای production انجام دهی.

اگر Train + Future data را fit کنی، ممکن است اطلاعات آینده وارد representation شود. در time-dependent problems باید temporal leakage را جدی بگیری.

106. Clustering و Time Series

K-Means روی raw time series الزاماً انتخاب خوبی نیست. ممکن است نیاز داشته باشی: shape-based distance, DTW, temporal embeddings, feature extraction را بررسی کنی.

108. Anomaly Detection در Payment

مثال: transaction_amount, velocity, merchant, country, hour, device, distance_from_usual_location

Isolation Forest می‌تواند baseline بسازد. اما Senior ML Engineer باید بداند: anomaly ≠ fraud

ممکن است anomaly: legitimate unusual purchase, new customer behavior, seasonal behavior باشد. بنابراین anomaly detection می‌تواند candidate generation باشد، نه الزاماً final fraud classifier.

109. Anomaly Detection و Threshold

مدل anomaly score می‌دهد: 0.62, 0.12, 0.81, 0.95. اما business system نیاز دارد: score > threshold

پس threshold باید بر اساس: false positives, false negatives, investigation capacity, business cost انتخاب شود.

110. Cost-sensitive Anomaly Detection

فرض کن: Cost(FP) = $2 ولی Cost(FN) = $1000

در این حالت threshold باید با توجه به asymmetry هزینه انتخاب شود. این همان اتصال مهم: ML Metric → Business Objective است.

111. Unsupervised Learning و Drift

2025: Normal behavior
2026: New behavior

مدل anomaly ممکن است رفتار جدید را anomaly تشخیص دهد. پس باید: retraining, threshold monitoring, drift detection, false positive monitoring داشته باشی.

112. K-Means چه زمانی انتخاب خوبی است؟

  • K تقریبی را می‌دانی
  • clusters نسبتاً spherical هستند
  • داده numeric است
  • distance معنی‌دار است
  • dataset نسبتاً بزرگ است
  • speed مهم است

113. Hierarchical چه زمانی؟

  • hierarchy مهم است
  • dataset خیلی بزرگ نیست
  • می‌خواهی dendrogram ببینی
  • تعداد clusterها از ابتدا مشخص نیست

114. DBSCAN چه زمانی؟

  • noise مهم است
  • clusterها arbitrary shape دارند
  • density نسبتاً مشابه است
  • distance meaningful است

115. HDBSCAN چه زمانی؟

  • density متفاوت است
  • noise وجود دارد
  • cluster count را نمی‌خواهی مشخص کنی
  • hierarchical density structure مفید است

116. GMM چه زمانی؟

  • probabilistic membership می‌خواهی
  • clusterها Gaussian-like هستند
  • uncertainty مهم است
  • elliptical clusters داری
  • density estimation هم مهم است

117. Isolation Forest چه زمانی؟

  • anomaly detection می‌خواهی
  • dataset بزرگ است
  • distribution مشخصی نمی‌خواهی فرض کنی
  • scalability مهم است

118. One-Class SVM چه زمانی؟

  • normal data داری
  • dataset نسبتاً manageable است
  • nonlinear boundary لازم داری
  • kernel-based approach ارزش دارد

120. مهم‌ترین تفاوت‌ها برای مصاحبه Senior

  • K-Means → Minimize Within Cluster Squared Distance
  • Hierarchical → Build Cluster Hierarchy
  • DBSCAN → Clusters = Dense Regions
  • HDBSCAN → Hierarchical Density + Variable Density
  • GMM → Model p(x) as Gaussian Mixture
  • Isolation Forest → Anomalies are easier to isolate
  • One-Class SVM → Learn a boundary around normal data

121. مهم‌ترین نکته Senior-Level

در Junior معمولاً می‌گویند:

«K-Means برای clustering است.»

اما Senior باید بگوید:

«قبل از انتخاب K-Means باید مشخص کنم مفهوم similarity چیست، آیا featureها scale مناسب دارند، آیا cluster structure واقعاً centroid-based است، آیا outlier داریم، آیا تعداد clusterها مشخص است، آیا data high-dimensional است و آیا business objective با internal clustering metrics هم‌راستا است.»

یعنی الگوریتم را از روی structure مسئله انتخاب می‌کنی، نه از روی اسم dataset.
