🌲 10. Decision Tree Concepts

حتماً. این بخش برای Senior ML خیلی مهم است، چون Decision Tree فقط یک الگوریتم نیست؛ بخش بزرگی از Random Forest، Gradient Boosting، XGBoost، LightGBM و CatBoost روی همین مفاهیم بنا شده‌اند.

من از پایه شروع می‌کنم و تا نکات ریاضی، تفاوت معیارها، pruning، complexity، feature importance و نکات مصاحبه‌ای می‌روم.

1. Decision Tree چیست؟

Decision Tree مدلی است که فضای Featureها را به مجموعه‌ای از نواحی تقسیم می‌کند.

مثلاً فرض کن می‌خواهیم تشخیص دهیم یک تراکنش:

Fraud / Not Fraud

است.

درخت ممکن است بپرسد:

Amount > 10,000? / \ Yes No / \ Night Transaction? Legit / \ Yes No / \ Fraud Legit

هر node یک تصمیم می‌گیرد.

ساختار کلی:

Root │ ┌──────┴──────┐ │ │ Internal Internal Node Node / \ / \ ... ... ... ... │ Leaf

2. اجزای Decision Tree

چهار مفهوم اصلی:

Root

اولین node.

Internal Node

یک شرط/split انجام می‌دهد.

مثلاً:

Age < 30
Branch

مسیر خروجی split.

Leaf

Prediction نهایی.

در Classification:

Leaf → class / probability

در Regression:

Leaf → numeric prediction

3. Splitting چیست؟

مهم‌ترین کار Decision Tree:

پیدا کردن بهترین Split.

فرض کن feature داریم:

Age

و می‌خواهیم:

Age < 30

یا:

Age >= 30

را بررسی کنیم.

Tree بررسی می‌کند:

آیا این split باعث می‌شود child nodeها pureتر شوند؟

اگر بله، split خوب است.

4. Pure و Impure یعنی چه؟

فرض کن یک node داریم:

100 samples Fraud = 50 Not Fraud = 50

این node بسیار:

Impure

است.

اما:

Fraud = 100 Not Fraud = 0

کاملاً:

Pure

است.

هدف Tree در Classification معمولاً این است که با split کردن:

Impurity ↓

شود.

5. Entropy

Entropy یکی از معیارهای impurity است.

فرمول:

$$H(S) = -\sum_{k=1}^{K} p_k \log_2(p_k)$$

که:

p_k

احتمال کلاس k در node است.

6. Entropy برای Binary Classification

اگر:

p = P(y = 1)

باشد:

$$H(p) = -p \log_2 p - (1-p) \log_2(1-p)$$

7. Entropy چه شکلی دارد؟

برای دو کلاس:

p = 0 Entropy = 0 p = 0.5 Entropy = 1 p = 1 Entropy = 0

یعنی:

Entropy ↑ 1│ ● │ / \ │ / \ │ / \ 0│●────────────● └──────────────→ p 0 .5 1

Maximum uncertainty زمانی است که:

p_1 = p_2 = 0.5

8. چرا Entropy در pure node صفر است؟

اگر:

p = 1

باشد:

$$-p \log p = -1 \times \log 1 = 0$$

پس:

H = 0

یعنی uncertainty نداریم.

9. Entropy برای چند کلاس

مثلاً سه کلاس:

A = 1/3 B = 1/3 C = 1/3

داریم:

$$H = -3 \left( \frac{1}{3} \log_2 \frac{1}{3} \right)$$

که تقریباً:

H = 1.585

است.

Maximum Entropy برای K کلاس:

$$H_{max} = \log_2 K$$

10. Information Gain

حالا سؤال مهم:

از بین splitهای مختلف، کدام را انتخاب کنیم؟

Information Gain این را اندازه می‌گیرد.

فرمول:

$$IG = H(parent) - \sum_j \frac{N_j}{N} H(child_j)$$

یعنی:

Information Gain = Parent uncertainty - Weighted child uncertainty

هرچه:

IG ↑

باشد، split بهتر است.

11. مثال Information Gain

فرض کن node اولیه:

10 samples 5 Cat 5 Dog

Entropy:

H(parent) = 1

حالا split انجام می‌دهیم:

Left: 5 Cat 0 Dog Right: 0 Cat 5 Dog

هر دو child کاملاً pure هستند:

H(left) = 0 H(right) = 0

بنابراین:

IG = 1 - 0 = 1

یعنی split عالی است.

12. اگر Split بد باشد؟

فرض کن:

Left: 3 Cat 2 Dog Right: 2 Cat 3 Dog

هر دو child هنوز تقریباً impure هستند.

پس:

H(children)

بالاست و:

IG

کم می‌شود.

13. نکته Senior درباره Information Gain

Information Gain یک معیار:

Absolute reduction in entropy

است.

اما یک مشکل مهم دارد.

14. مشکل Information Gain — Many-Valued Features

فرض کن feature:

Customer_ID

داریم.

اگر هر Customer_ID تقریباً unique باشد، Tree می‌تواند:

ID = 1 ID = 2 ID = 3 ...

بسازد.

این ممکن است training data را تقریباً perfectly جدا کند.

پس:

IG

ممکن است زیاد شود.

ولی مدل:

Generalize

نمی‌کند.

این یک شکل کلاسیک از:

Overfitting

است.

15. Gain Ratio

Gain Ratio برای کاهش این bias معرفی شده است.

فرمول:

$$Gain Ratio = \frac{Information Gain}{Split Information}$$

16. Split Information

فرمول:

$$SplitInfo = -\sum_j \frac{N_j}{N} \log_2 \frac{N_j}{N}$$

این معیار می‌گوید split چقدر داده را به قسمت‌های مختلف تقسیم کرده است.

17. چرا Gain Ratio مفید است؟

فرض کن:

Feature A → 2 groups Feature B → 1000 groups

Feature B ممکن است Information Gain بالایی بگیرد فقط به خاطر تعداد زیاد partitions.

Gain Ratio این را penalize می‌کند.

18. Gain Ratio در کدام الگوریتم معروف است؟

به‌خصوص در:

C4.5

استفاده شده است.

در حالی که:

ID3

معمولاً با:

Information Gain

شناخته می‌شود.

19. Gini Impurity

معیار بسیار مهم دیگر:

$$Gini = 1 - \sum_k p_k^2$$

است.

20. Gini برای Binary

اگر:

p = P(y = 1)

باشد:

$$Gini = 1 - p^2 - (1-p)^2$$

که ساده می‌شود:

$$Gini = 2p(1-p)$$

21. Gini چه زمانی صفر است؟

اگر node کاملاً pure باشد:

p = 1

پس:

Gini = 0

اگر:

p = 0

هم:

Gini = 0

22. Maximum Gini

برای binary classification:

p = 0.5

داریم:

Gini = 0.5

پس:

Pure → Gini = 0 Maximum uncertainty → Gini = 0.5

برای Binary Classification:

در عمل معمولاً:

Gini و Entropy اغلب splitهای مشابهی انتخاب می‌کنند.

24. آیا Gini همیشه بهتر است؟

نه.

تفاوت عملی اغلب کوچک است.

در بسیاری از datasets:

Gini ≈ Entropy

از نظر performance.

پس انتخاب را با:

validation / CV

انجام بده، نه با فرض اینکه یکی همیشه بهتر است.

25. Splitting برای Regression

در Regression دیگر کلاس نداریم.

پس Entropy/Gini مناسب نیستند.

می‌توان از:

MSE / Variance Reduction

استفاده کرد.

مثلاً:

$$MSE = \frac{1}{N} \sum_i (y_i - \bar{y})^2$$

Tree splitی را انتخاب می‌کند که impurity regression را بیشتر کاهش دهد.

26. Prediction در Regression Tree

در یک leaf معمولاً:

$$\hat{y}_{leaf} = \frac{1}{N} \sum_i y_i$$

یعنی:

Mean target values داخل leaf.

به همین دلیل outlierها می‌توانند روی prediction اثر بگذارند.

29. Greedy Splitting

Decision Tree معمولاً:

Greedy

است.

یعنی در هر node:

بهترین split فعلی را انتخاب می‌کند.

اما:

تضمینی نیست که بهترین global tree را پیدا کند.

این نکته خیلی مهم است.

30. چرا Tree Greedy است؟

پیدا کردن optimal tree در حالت کلی مسئله بسیار سختی است.

پس الگوریتم به‌جای جستجوی تمام treeهای ممکن:

Best split now ↓ Best split next ↓ ...

را انجام می‌دهد.

31. مشکل Greedy Strategy

ممکن است:

Best split now

در بلندمدت:

بهترین tree را ایجاد نکند.

ولی در عمل greedy tree induction بسیار مؤثر است.

32. Tree Depth

Depth تعداد سطوح tree است.

مثلاً:

Depth 0 Root Depth 1 Root / \ Depth 2 Root / \ A B / \ / \

33. Depth چه اثری دارد؟

با افزایش depth:

Depth ↑

ظرفیت مدل افزایش می‌یابد.

پس معمولاً:

Bias ↓ Variance ↑

34. Tree خیلی کم‌عمق

مثلاً:

max_depth = 1

Decision Stump است.

ممکن است:

Underfit

کند.

35. Tree خیلی عمیق

مثلاً:

max_depth = unlimited

ممکن است:

Training error ≈ 0 Validation error ↑

شود.

یعنی:

Overfitting.

36. Leaf Size

یکی دیگر از hyperparameterهای مهم:

Minimum samples per leaf

است.

مثلاً:

min_samples_leaf = 10

یعنی هر leaf باید حداقل 10 sample داشته باشد.

37. اثر Leaf Size

اگر:

min_samples_leaf ↑

باشد:

Tree complexity ↓ Variance ↓ Bias ↑

اگر خیلی کوچک باشد:

Leaf size = 1

مدل می‌تواند بسیار flexible شود.

38. Depth vs Leaf Size

هر دو:

Complexity را کنترل می‌کنند.

اما متفاوت هستند.

max_depth

کنترل می‌کند:

چند سطح می‌توانیم برویم.
min_samples_leaf

کنترل می‌کند:

هر ناحیه حداقل چند observation داشته باشد.

39. Pre-Pruning

Pre-Pruning یعنی:

قبل از رشد کامل، رشد tree را محدود کنیم.

پارامترها:

max_depth min_samples_split min_samples_leaf max_leaf_nodes max_features min_impurity_decrease

40. مثال Pre-Pruning

به جای اینکه tree تا pure شدن کامل رشد کند:

max_depth=5

می‌گذاری.

Tree بیشتر از depth 5 رشد نمی‌کند.

41. مزیت Pre-Pruning

training سریع‌تر tree کوچک‌تر overfitting کمتر memory کمتر

42. مشکل Pre-Pruning

ممکن است:

early stopping بیش از حد شدید

باشد.

یعنی splitی که الان ظاهراً کوچک به نظر می‌رسد، ممکن بود در depthهای بعدی بسیار مفید شود.

پس:

Underfitting

ممکن است رخ دهد.

43. Post-Pruning

در Post-Pruning:

Grow Tree ↓ Large Tree ↓ Prune unnecessary branches

ابتدا tree را می‌سازی، سپس branches کم‌ارزش را حذف می‌کنی.

44. چرا Post-Pruning؟

ممکن است اطلاعات لازم برای تصمیم‌گیری درباره ارزش یک branch را فقط بعداً داشته باشیم.

پس:

Post-pruning

گاهی انعطاف بیشتری دارد.

45. Cost-Complexity Pruning

یکی از روش‌های معروف:

Minimal Cost-Complexity Pruning

است.

Objective:

$$R_{\alpha}(T) = R(T) + \alpha |T|$$

که:

R(T): tree error |T|: تعداد leaves α: complexity penalty

است.

46. Interpretation

اگر:

α = 0

باشد:

complexity penalty نداریم.

اگر:

α ↑

شود:

tree کوچک‌تر ترجیح داده می‌شود.

یعنی:

α ↑ ↓ Leaves ↓ ↓ Complexity ↓ ↓ Variance ↓ Bias ↑

48. Feature Importance

Decision Tree می‌تواند importance هر feature را تخمین بزند.

یکی از روش‌های رایج:

Mean Decrease in Impurity — MDI

است.

49. MDI چگونه محاسبه می‌شود؟

اگر feature j در split باعث reduction در impurity شود:

ΔI

اهمیت آن feature به این reduction وابسته است.

به صورت مفهومی:

$$Importance_j = \sum_{splits\ using\ j} weighted\ impurity\ reduction$$

وزن node معمولاً بر اساس تعداد samples عبوری از node است.

50. مثال

فرض کن:

Feature A → impurity reduction = 0.4 Feature B → 0.1 Feature C → 0.05

A اهمیت بیشتری دارد.

اما یک نکته بسیار مهم:

Feature Importance به معنی Causality نیست.

اگر:

A important = 0.8

باشد، نمی‌توانی نتیجه بگیری:

A باعث target شده است.

51. مشکل MDI Feature Importance

MDI می‌تواند نسبت به:

High-cardinality features

bias داشته باشد.

مثلاً:

Customer_ID

یا featureهایی با تعداد زیادی possible split.

همچنین correlated features می‌توانند importance را بین خودشان تقسیم کنند یا interpretation را دشوار کنند.

52. Permutation Importance

روش دیگری:

Permutation Importance

است.

ایده:

1. مدل را روی validation data اجرا کن. 2. Performance را اندازه بگیر. 3. Feature A را shuffle کن. 4. دوباره performance را اندازه بگیر. 5. افت performance را اندازه بگیر.

اگر:

Performance_original - Performance_permuted

زیاد باشد:

feature مهم‌تر است.

53. مزیت Permutation Importance

به جای نگاه کردن به internal tree structure:

effect feature on predictive performance

را اندازه می‌گیرد.

اما باز هم:

correlation بین features

می‌تواند interpretation را مشکل کند.

54. Correlated Features و Importance

فرض کن:

X1 = Age X2 = Age + noise

هر دو اطلاعات مشابه دارند.

اگر X1 را shuffle کنی:

X2 هنوز اطلاعات را نگه می‌دارد.

پس افت performance ممکن است کم باشد.

نتیجه:

X1 ظاهراً کم‌اهمیت به نظر می‌رسد.

در حالی که اطلاعاتش واقعاً مهم است.

58. Diversity در Ensemble

این اصل بسیار مهم است:

Ensemble فقط به مدل‌های قوی نیاز ندارد؛ diversity بین مدل‌ها هم مهم است.

اگر:

باشد، averaging فایده زیادی ندارد.

اما اگر خطاها تا حدی متفاوت باشند:

Correlation(errors) ↓

59. ارتباط Random Feature Selection با Bias-Variance

Random Feature Selection:

Tree diversity ↑ Correlation ↓ Variance of ensemble ↓

ولی randomness زیاد می‌تواند:

Bias ↑

کند.

پس باز هم:

Bias–Variance Tradeoff

داریم.

60. max_features

68. Entropy vs Gini — نکته مصاحبه

اگر interviewer پرسید:

«Gini یا Entropy؟»

جواب Senior:

هر دو impurity measure هستند و معمولاً رفتار مشابهی دارند. Gini از نظر محاسباتی کمی ساده‌تر است، در حالی که Entropy از مفهوم information-theoretic می‌آید. در بسیاری از datasets تفاوت predictive performance ناچیز است، بنابراین انتخاب را بهتر است با validation انجام دهیم.

69. Information Gain vs Gain Ratio

اگر پرسید:

چرا Gain Ratio ساخته شد؟

جواب:

Information Gain به features با تعداد زیادی possible splits یا categories تمایل دارد. Gain Ratio با نرمال‌سازی Information Gain بر اساس Split Information این bias را کاهش می‌دهد.

Data ↓ split / \ split split / \ / \ ...

در نهایت ممکن است هر leaf:

1 sample

داشته باشد.

در نتیجه:

Training error → 0

ولی:

Generalization error ↑

77. Feature Importance ≠ Feature Selection

Feature importance می‌گوید:

کدام feature در مدل اهمیت بیشتری داشته است.

Feature selection می‌گوید:

کدام featureها را نگه داریم و کدام را حذف کنیم.

ممکن است یک feature importance پایین داشته باشد ولی حذف آن به خاطر interactionها performance را خراب کند.

78. Feature Importance ≠ Causal Importance

این جمله را حتماً به خاطر بسپار:

$$Predictive\ importance \neq Causal\ importance$$

اگر feature X prediction را بهتر کند، لزوماً:

X → Y

را ثابت نمی‌کند.

79. یک مثال واقعی برای Fraud Detection

فرض کن:

Features: amount merchant_id hour country device_id velocity

Tree ممکن است یاد بگیرد:

velocity > threshold ↓ high fraud probability

اما اگر:

velocity

با یک feature دیگر highly correlated باشد، importance ممکن است بین آن‌ها پخش شود.

پس فقط با Feature Importance تصمیم به حذف feature نگیر.

80. Senior Interview Cheat Sheet

Entropy
$$H = -\sum p \log p$$

اندازه‌گیری uncertainty.

Information Gain
$$IG = H(parent) - H(children)$$

کاهش entropy.

Gini
$$Gini = 1 - \sum p^2$$

اندازه‌گیری impurity.

Gain Ratio
$$GR = \frac{IG}{SplitInfo}$$

کاهش bias نسبت به multi-valued features.

Depth
Depth ↑ ⇒ Bias ↓, Variance ↑
Leaf Size
Leaf Size ↑ ⇒ Complexity ↓
Pre-Pruning

محدود کردن رشد tree قبل از کامل شدن.

Post-Pruning

ساخت tree و سپس حذف branches غیرضروری.

Random Feature Selection

انتخاب subset تصادفی از features در هر split برای افزایش diversity و کاهش correlation بین trees.
